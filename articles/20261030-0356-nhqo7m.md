毎回同じコマンドを手で打ち直したり、ウィンドウのサイズをマウスで調整したりするたびに時間が溶けていた。そんな細かいストレスを減らすために、無料で導入できるツールを試し続けた結果、今では毎日の作業がスムーズになった10個を紹介する。

## iTerm2 でタブ・分割が楽になった
以前は標準のターミナルで複数のセッションを開くと、ウィンドウが増えて把握しきれなかった。iTerm2 を入れてからは、ショートカットでペイン分割やタブ移動が一瞬でできる。
```bash
brew install --cask iterm2
```
今では `Cmd+D` で縦分割、`Cmd+Shift+D` で横分割し、作業ごとにペインを切り替えるだけで済む。

## Homebrew でパッケージ管理が一元化された
必要な CLI ツールをその都度公式サイトからダウンロードしていた頃は、バージョン違いやパス通しでハマりがちだった。Homebrew なら一行でインストール・アップデートが完結する。
```bash
brew install git node python
brew upgrade
```
`brew bundle` で `Brewfile` を共有すれば、チーム全員が同じ環境を数分で揃えられるようになった。

## Visual Studio Code で拡張機能が開発を加速した
エディタを切り替えるたびに設定をやり直すのが面倒で、軽量なエディタを探し続けていた。VS Code は拡張マーケットが豊富で、言語ごとのリンター・フォーマッタをワンクリックで導入できる。
```json
// settings.json に追加
"editor.formatOnSave": true,
"editor.codeActionsOnSave": { "source.fixAll.eslint": true }
```
保存するだけで自動整形が走り、レビュー指摘が激減した。

## Rectangle でウィンドウ整理がキーボードだけで完結する
画面分割をマウスでドラッグしていた頃は、デュアルモニタでも作業スペースが狭く感じられた。Rectangle ならショートカットで左右半分、四分割、最大化が即座にできる。
```bash
brew install --cask rectangle
```
`Ctrl+Option+←/→` で左右半分、`Ctrl+Option+Cmd+F` で全画面。手がキーボードから離れなくなった。

## fzf で履歴・ファイル検索が瞬時に終わる
`history | grep` や `find` を打ち直すのが億劫で、目的のコマンドやファイルにたどり着くまで数十秒かかっていた。fzf をシェルに組み込むと、曖昧検索で目的が即座にヒットする。
```bash
brew install fzf
$(brew --prefix)/opt/fzf/install
```
`Ctrl+R` でコマンド履歴、`Ctrl+T` でカレントディレクトリ以下のファイルを絞り込めるようになり、探す時間がほぼゼロになった。

## gh で GitHub 操作がターミナルから完結する
PR 作成や Issue 確認のためにブラウザを開くたびにコンテキストスイッチが発生していた。GitHub CLI `gh` を使えば、リポジトリ操作をコマンド一発で行える。
```bash
gh auth login
gh pr create --title "Fix bug" --body "Description"
gh issue list --assignee @me
```
レビュー依頼やマージも `gh pr merge` で完了し、ブラウザ往復がなくなった。

## direnv でプロジェクトごとの環境変数が自動切替される
`.env` ファイルを手で `source` するのを忘れて、本番用のキーをローカルで使ってしまう事故があった。direnv を入れると、ディレクトリ移動時に `.envrc` を自動読み込みしてくれる。
```bash
brew install direnv
echo 'eval "$(direnv hook zsh)"' >> ~/.zshrc
echo 'export DATABASE_URL=postgres://local' > .envrc
direnv allow
```
`cd` するだけで正しい変数がセットされ、事故がゼロになった。

## asdf で言語バージョンをプロジェクト単位で固定できる
`nvm` `rbenv` `pyenv` などを併用すると、シェルの初期化が重くなり、切り替え忘れでビルドエラーが出ていた。asdf ならプラグイン方式で全言語を一元管理できる。
```bash
brew install asdf
asdf plugin add nodejs
asdf install nodejs 20.11.0
asdf local nodejs 20.11.0
```
`.tool-versions` をリポジトリに置けば、クローン後に `asdf install` 一発で全員が同じバージョンで動く。

## HTTPie で API テストが読みやすい出力でできる
`curl` の長いオプションを覚えるのが辛く、レスポンスが生の JSON で見づらかった。HTTPie は直感的な構文とカラー整形出力で、デバッグが劇的に楽になる。
```bash
brew install httpie
http GET https://api.example.com/users Authorization:"Bearer $TOKEN"
```
ステータスコード・ヘッダー・ボディが色分けされ、即座に異常を見つけられるようになった。

## Raycast でランチャー・クリップボード・スニペットが統合された
Spotlight や Alfred の有料機能に頼っていたが、無料で同等以上のことができる Raycast に乗り換えた。拡張ストアで GitHub・Jira・Docker 連携も追加できる。
```bash
brew install --cask raycast
```
`Cmd+Space` で起動し、スニペット展開やクリップボード履歴検索、ウィンドウ操作までキーボードだけで完結する。
