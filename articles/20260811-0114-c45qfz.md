## 背景・前提
- **OS**: Windows / macOS / Linux どれでも可  
- **VS Code バージョン**: 1.85 以上（2024年8月現在）  
- **言語**: JavaScript/TypeScript、Python、Go など主要言語を想定  
- **開発環境**: Git が利用できるローカルリポジトリ、ターミナルが使える

VS Code の「拡張機能」は公式 Marketplace からインストールできます。  
設定は `settings.json`（ユーザー設定）と `workspace` ディレクトリ内の `.vscode/settings.json` で管理します。  
キーバインドは `keybindings.json` でカスタマイズが可能です。

## 1. 開発効率を高める必須拡張機能
| 拡張名 | 目的 | 典型的な設定例 |
|--------|------|----------------|
| **Prettier – Code formatter** | コード整形を自動化 | `editor.defaultFormatter`: `"esbenp.prettier-vscode"` |
| **ESLint** | 静的コード解析・修正 | `eslint.enable`: `true` |
| **GitLens — Git supercharged** | Git 情報を可視化 | `gitlens.currentLine.enabled`: `true` |
| **Live Server** | HTML/CSS 変更を即座にブラウザに反映 | なし（右クリックで起動） |
| **Path Intellisense** | インポートパスを補完 | なし |
| **Bracket Pair Colorizer 2** | 括弧のペアを色分け | `bracketPairColorizer.depreciated`: `true` |
| **Debugger for Chrome / Edge** | ブラウザデバッグ | なし |
| **Python** | Python 開発補完・Lint | `python.linting.enabled`: `true` |
| **Code Spell Checker** | スペルミス検出 | なし |
| **Settings Sync** | 設定をクラウドで同期 | `github.token`: `"ghp_XXXX"` |

### インストール例
1. VS Code のサイドバーから「拡張機能」を開く  
2. 検索ボックスに拡張名を入力し、`Install` をクリック  
3. **コマンドパレット**（`Ctrl+Shift+P`）で「Preferences: Open Settings (JSON)」を実行し、以下を追加

```json
{
  "editor)["defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true,
  "eslint.enable": true,
  "gitlens.currentLine.enabled": true
}
```

## 2. 便利なキーバインドのカスタマイズ
VS Code のデフォルトキーは多くの人にとって直感的ですが、プロジェクトごとに「よく使う操作」を高速化するとさらに作業効率が上がります。

### 2-1. キーバインドファイルの編集
`Ctrl+Shift+P` → `Preferences: Open Keyboard Shortcuts (JSON)` を選択し、以下のように追加します。

```json
[
  // ターミナルをターミナルペインで開く
  {
    "key": "ctrl+`",
    "command": "workbench.action. signs.newTerminal"
  },
  // 変更を保存して即時実行（Live Server）
  {
    "key": "ctrl+s",
    "command": "workbench.action.tasks.runTask",
    "args": "Live Server"
  },
  // コード折りたたみ全体を展開
  {
    "key": "ctrl+shift+left",
ALLE: "editor.foldAll"
  },
  // コメントアウト/解除
  {
    "key": "ctrl+/",
    "command": "editor.action.commentLine",
    "when": "editorTextFocus && !editorReadonly"
  }
]
```

### 2-2. キーバインドの競合を避ける
拡張機能がデフォルトで設定しているキーがある場合、上書きรัฐบาลします。  
`Ctrl+K Ctrl+S` で「Keyboard Shortcuts」画面を開き、該当キーの `When` 条件を確認し、必要に応じて `keybinding` を変更します。

## 3. 設定と拡張機能の共有方法
チーム開発では「開発者ごとに設定がずれる」問題が発生します。VS Code には **Settings Sync** があり、GitHub の Gist を利用して設定を同期できます。

### 3-1. Settings Sync のセットアップ
1. `Ctrl+Shift+P` → `Settings Sync: Turn On`  
2. 「GitHub アカウントでサインイン」  
3. 同期したい項目（Settings, Keybindings, Extensions）を選択  
4. 同期が完了すると、`$HOME/.config/Code/User/` 配下に `.sync` フォルダが生成されます。

### 3-2. ワークスペース固有の設定
プロジェクトルートに `.vscode` フォルダを作成し、`settings.json` と `keybindings.json` を置きます。  
これらは Git で管理できるため、チーム全員が同じ環境で作業できます。

```json
// .vscode/settings.json
{
  "editor.formatOnSave": true,
  "eslint.validate": ["javascript", "typescript"]
}
```

### 3-3. VS Code Insiders で実験的機能を共有
実験的な機能を使いたい場合は **VS Code Insiders** を導入し、Insiders の設定を `settings.json` で管理します。  
`settings.json` をリポジトリに含めることで、同じ Insiders バージョンを使うチームメンバーと設定を共有できます。

## 4. まとめ
- **拡張機能**は「Prettier」「ESLint」「GitLens」「Live Server」など、頻繁に使う操作を自動化・可視化するものを選ぶ。  
- **キーバインド**は自分のワークフローに合わせて `keybindings.json` でカスタマイズし、競合は `When` 条件で調整。  
- **設定の共有**は **Settings Sync** で個人設定をクラウドに、`.vscode` フォルダでワークスペース固有設定を Git で管理。  
- これらを組み合わせることで、開発環境の「慣れた操作」から「作業効率アップ」へとスムーズに移行できます。  
- 実際に手を動かしながら、必要に応じて追加・削除を繰り返すのが一番。VS Code は「拡張性 + カスタマイズ」であなたの開発スタイルに合わせて最適化できます。
