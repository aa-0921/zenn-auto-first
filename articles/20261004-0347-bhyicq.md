## `fzf` でディレクトリ・ファイル検索が一瞬
`find` や `ls` で目的のファイルを探すのに時間がかかった。特に深い階層のファイルや似た名前のファイルは目grepするのが辛い。`fzf` はインクリメンタルサーチでファイルを絞り込んでくれて、Enter で開ける。`.zshrc` にキーバインドを設定すると、`Ctrl+T` でファイル検索 → `Enter` でパスが補完される。

```bash
# fzf + fd 連携
export FZF_DEFAULT_COMMAND='fd --type f --hidden --exclude ".git"'
export FZF_CTRL_T_COMMAND="$FZF_DEFAULT_COMMAND"
```

## `bat` でコードレビューが快適に
`cat` はシンタックスハイライトもないし、行数もわからない。`bat` は `cat` の置き換えで、シンタックスハイライト・行番号・Git 差分表示ができる。`bat hoge.py` とするだけで見やすくなる。`alias cat='bat'` も便利。

```bash
# ファイル内容表示
bat main.py
# Git 差分付き表示
bat --diff main.py
```

## `ripgrep` で検索が速すぎてびっくり
`grep -r` は遅くて仕方なかった。`.gitignore` も無視してくれなくてノイズが多い。`rg` は Rust 製で爆速。`.gitignore` を自動で読み飛ばしてくれて、再帰検索もデフォルト。

```bash
# .env ファイルを除外して "password" を検索
rg "password" --glob '!*.env'
```

## `httpie` で API テストが簡単に
`curl` のオプションが覚えにくくて、POST やヘッダー設定が面倒だった。`http` コマンドは直感的な構文でリクエストを送れる。JSON レスポンスも自動で整形してくれる。

```bash
# POST リクエスト
http POST api.example.com/users name=John email=john@example.com
```

## `tig` で Git 履歴が視覚化される
`git log` は見づらくて、コミットメッセージも一行ずつ確認するのが面倒。`tig` は CUI の Git クライアントで、コミットツリーを視覚的に表示。`git status` や `git diff` も `tig` 内で確認できる。

```bash
# コミット履歴表示
tig
# ステージングエリア表示
tig status
```

## `jq` で JSON 処理がワンライナー
API レスポンスや JSON ファイルを `grep` や `sed` で処理するのは面倒くさすぎた。`jq` は JSON をフィルタリング・整形できる。`.[]` や `| select()` で必要なデータを抽出できる。

```bash
# ユーザー名だけ抽出
curl -s api.example.com/users | jq -r '.[].name'
```

## `tmux` でセッション管理が快適に
ターミナルを閉じるたびに作業状態が失われていた。`tmux` はターミナル多重化ツールで、セッションを保存できる。`tmux new -s dev` でセッションを開始し、`tmux attach` で再接続できる。

```bash
# 新しいセッション作成
tmux new -s dev
# セッション一覧表示
tmux ls
# セッション再接続
tmux attach -t dev
```

## `watch` でコマンドを定期実行
ログ監視やビルドステータス確認に手動で何度もコマンドを打っていた。`watch -n 2 'ls -la'` で 2 秒ごとにコマンドを再実行してくれる。

```bash
# 2秒ごとにディスク使用量を確認
watch -n 2 'df -h'
```

## `autojump` で cd が爆速に
`cd ~/project/app/frontend/components` のように深いパスを毎回打つのが面倒くさすぎた。`autojump` は過去の `cd` 履歴を学習して、`j proj` で自動補完してくれる。

```bash
# プロジェクトディレクトリに移動
j proj
# 学習データ確認
j --stat
```

## `gh` で GitHub 操作が CLI で完結
ブラウザでプルリク作成や Issue 確認をするのは時間がかかった。`gh` は GitHub CLI で、PR 作成・マージ・Issue 確認がコマンドでできる。

```bash
# プルリク作成
gh pr create --title "Add feature" --body "New feature added"
# Issue 一覧表示
gh issue list
```

## まとめ
CLI ツールを使うことで、マウスやブラウザを行き来する手間がなくなり、コマンド一つで作業が完結するようになった。特に `fzf`、`bat`、`ripgrep`、`httpie` は即座に生産性が上がった。まずは 1 つ試してみてほしい。
