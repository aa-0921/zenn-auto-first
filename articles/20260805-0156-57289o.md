## React Developer Tools でコンポーネントの状態を一目で確認

Reactコンポーネントのpropsやstateを確認するたびに、console.logを何度も書き換えていた。出力が大量になりすぎて、意図した値がどこにあったかを探すのに何度もスクロールしていた。拡張機能をインストールし、開発者ツールの「Components」タブを開くと、コンポーネントツリーがそのまま表示される。```F12 → Components```propsの流れやstateの変化をインスペクター上で直接追えるようになり、ログを消す手間がなくなった。デバッグ中の集中力が途切れなくなり、問題の切り分けが一瞬でできるようになった。

## Vue.js Devtools でリアクティブなデータを追跡

Vueアプリのリアクティブなデータバインディングが想定通りに動かない時、DOMをいちいち辿って原因を探っていた。拡張機能をインストールし、開発者ツールのVueタブを選択すると、コンポーネントツリーとstateが一覧で表示される。```F12 → Vue```stateの値をリアルタイムで編集してUIの反応を即座に確認できるようになり、ブレークポイントを設定する手間がなくなった。データの流れを視覚的に追えるようになった。

## Redux DevTools Extension で状態変化をタイムトラベル

Reduxストアの状態がいつどこで変わったのかをconsole.logだけで追跡していた。アクションの履歴を手動で辿るのは大変で、バグの切り分けに何時間もかかっていた。拡張機能をインストールすると開発者ツールにReduxタブが追加され、アクションの履歴とstateの変化が時系列で表示される。```F12 → Redux```タイムトラベルデバッグで過去のstateに巻き戻せるようになり、バグの原因が一瞬で特定できるようになった。

## JSON Formatter でレスポンスを瞬時に整形

APIレスポンスの生JSONをブラウザで開くと見づらく、整形するたびにオンラインツールに貼り付けていた。コピー＆ペーストの手間が積み重なり、作業の流れが途切れ続けていた。拡張機能をインストールし、JSONを含むページを開くと自動的に整形して表示される。```chrome://extensions```フォーマットや色分けも適切で、レスポンスの構造を一目で把握できるようになった。手動での整形が完全に不要になった。

## CSS Peeper でデザイン情報をポップアップで取得

ウェブページの素晴らしいデザインを模倣しようとしたが、インスペクターでCSSを調べるのが手間だった。色のHEX値やフォントサイズを調べるたびに、別のタブでデザインガイドラインを開いて照合していた。拡張機能をインストールし、ページ上で要素をクリックするとスタイルパレットがポップアップで開く。```Ctrl + Shift + C```色の値やフォント情報をすぐに確認でき、デザインの転記作業が大幅に短縮された。

気になるウェブサイトがどのような技術で構築されているかを調べるたびに、ソースコードを眺めていた。CMSやフレームワークの特定に時間が
