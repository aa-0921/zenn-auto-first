## 背景と前提
- **学歴と職歴**：大学卒業後、営業職に5年従事。顧客との折衝や交渉はスキルが身についたものの、自分に「技術的な価値を提供できる」実感が薄く、転職を決意。
- **転職の動機**：技術に触れる仕事で、問題解決のプロセスを自分でコントロールしたいという欲求と、業界の成長性に魅了されたこと。
- **学習環境**：独学でプログラミングを始め、オンライン講座と実務を組み合わせた学習スタイルを採用。当時は平日の勤務後と週末を活用し、1年で基礎を固めました。

## 学習と実践のステップ
### 1. 言語選定と学習リソースの整理
まずは「何を学ぶか」を決めます。転職先の求人を眺めると、Python・JavaScript・Go が頻出。自分は汎用性と学習のしやすさから **Python** を選び、以下の教材を活用しました。

```markdown
- ドットインストールのPythonコース（基礎からアプリケーションまで）
- 書籍「パイソンデータサイエンス入門」章毎に実装しながら復習
- GitHubで同僚やコミュニティが公開している小規模プロジェクトをフォークし、PRを出す練習
```

### 2. 小規模プロジェクトで実践力を養う
学習だけでは実感が湧きにくいため、**実務に近い小さなツール**を作りました。例として、タスク管理CLIを作成し、以下の機能を実装しました。

```python
# task_manager.py
import json
from pathlib import Path

DATA_FILE = Path.home() / ".task_manager.json"

def load_tasks():
    if DATA_FILE.exists():
        return json.loads(DATA_FILE.read_text())
    return []

def save_tasks(tasks):
    DATA_FILE.write_text(json.dumps(tasks, ensure_ascii=False, indent=2))

def add_task(description):
    tasks = load_tasks()
    tasks.append({"id": len(tasks)+1, "desc": description, "done": False})
    save_tasks(tasks)

def list_tasks():
    for t in load_tasks():
        status = "✅" if t["done"] else "❌"
        print(f"{t['id']}: {status} {t['desc']}")

# 実行例
if __name__ == "__main__":
    add_task("ブログ記事の執筆")
    list_tasks()
```

このプロジェクトを通じて、**ファイルI/O、JSON handling、CLI設計**の感覚を掴み、実際に「自分で作って動かす」楽しさを体感しました。

### 3. アウトプットとフィードバックの習慣化
- **ブログやQiitaにアウトプット**：学んだことを記事にすることで、知識の定着と他者からの質問や指摘を得られました。
- **コードレビュー**：友人やオンラインコミュニティにプルリクエストを出し、フィードバックをもらうことでコード品質が向上。

## 現場で感じる手応えと転職メリット
### 1. チームでの協働の実感
入社後は **Agile のスプリント** に参加し、週ごとにタスクを共有。コードレビューの文化が浸透しており、PR が通るまでに何度も議論を重ねました。実際に「自分のコードがチームの品質向上に貢献している」実感が大きく、やりがいにつながりました。

### 2. 成長スピードの早さ
転職初年度に **月間で1〜2件の小さなリリース** を担当。リリースサイクルが短いことで、フィードバックループが速く、技術的な知見が瞬時に吸収できました。結果として、半年で自分のスキルセットが以前の営業時代と比べて3倍以上に拡張されたと実感しています。

### 3. キャリアパスの選択肢が広がる
技術スタックの幅が広がり、 **フロントエンドからバックエンド、データエンジニアへの転向** も可能に。転職エージェントから得た情報と自己学習で、次なるステップとして「データ分析基盤の構築」を目指す計画を立てています。

## まとめ
20代後半・30代からエンジニアを目指すことは、単に「学ぶ」だけでなく、**実践・アウトプット・フィードバック** を繰り返すことが成功の鍵です。  
- **学習**は目的を明確にし、小さなプロジェクトで成果を出すことが大切。  
- **現場経験**はチームでの協働やリリースサイクルを通じて実感でき、転職後のキャリア選択肢を広げる。  
- **転職**は自分の強みを再確認し、新しい技術スタックに挑戦する絶好のチャンス。

これらの経験を踏まえて、同じようにキャリアチェンジを考えている方は、**まずは小さなコードを書くことから始め**、徐々にスケールアップしていくことをおすすめします。実感できる「良さ」が、あなたの次の一歩を後押ししてくれます。
