```json
{
  "theme": "dark",
  "autoFormat": true,
  "lineNumbers": false
}
```
拡張機能のオプションページに上記のように設定を書き込むと、JSONビューアが自動で整形し、行番号やテーマを好みに変更できるようになった。これでレスポンスを確認するだけの作業が数秒で終わり、デバッグサイクルが格段に速まった。

## Wappalyzerでサイトの技術スタックをすぐ把握
新しいサービスを調査するとき、どのフレームワークやライブラリが使われているかを手動でソースを読んで探していた。見逃しも多く、調査に時間がかかっていた。
```json
{
  "detect": ["CMS", "Frameworks", "Libraries", "Analytics"],
  "notify": true
}
```
オプションで検出対象と通知を有効にすると、ツールバーのアイコンがサイトの技術スタックを数字で示すようになった。クリックすると詳細な一覧がポップアップで表示され、調査が一瞬で終わるようになった。

## Lighthouseでパフォーマンス改善点を可視化
ページの読み込み速度が遅いと感じても、どこがボトルネックかを手動でネットワークタブを眺めて探していた。改善ポイントが見えず、試行錯誤に時間を費やしていた。
```json
{
  "extends": "lighthouse:default",
  "settings": {
    "formFactor": "mobile",
    "precompress": true,
    "emulateNetworkConditions": false
  }
}
```
Lighthouseの設定ファイルに上記のようにモバイルシミュレーションと圧縮有効化を追加し、監査を実行すると、レポートに「使用していないJavaScript」「大きな画像」など具体的な提案が出るようになった。これにより、改善すべきポイントをすぐに特定し、修正後のスコア向上を実感できた。

## React Developer Toolsでコンポーネント状態をリアルタイム確認
Reactアプリのデバッグで、stateやpropsの変化をコンソールにログを出して確認していた。ログが多くなり、目的の変数を見つけ出すのに苦労していた。
```json
{
  "highlightUpdates": true,
  "traceUpdates": true,
  "renderer": "react"
}
```
拡張機能の設定でハイライトとトレースを有効にすると、コンポーネントツリーを選択したときに、更新が発生したコンポーネントが色でハイライトされ、propsの変化もリアルタイムで表示されるようになった。これにより、状態遷移の追跡が格段に楽になった。

## Redux DevToolsでステート遷移をタイムトラベル
Reduxを使っていると、アクションのディスパッチ順や状態変化をログで追っていたが、過去の状態に戻して再現するのが手間だった。デバッグに時間が取られていた。
```json
{
  "actionSanitizer": false,
  "stateSanitizer": false,
  "monitor": {
    "type": "ChartMonitor",
    "options": { "width": 800, "height": 400 }
  }
}
```
オプションでサニタイザーを無効にし、ChartMonitorを有効にすると、タイムトラベルスライダーで過去のアクションに戻り、状態の差分をグラフで確認できるようになった。これにより、バグの再現が瞬時に行えるようになり、修正サイクルが短縮された。

## Vue.js devtoolsでコンポーネントのプロパティを即確認
Vueアプリを開発しているとき、テンプレートのデータバインディングがうまくいかず、どのプロパティが渡されているかをコンソールで確認していた。探すのに手間取っていた。
```json
{
  "devtools": true,
  "logPerformance": true,
  "trace": true
}
```
Vue CLIの設定に上記を追加し、devtoolsを有効にすると、コンポーネント選択時にプロパティと状態がパネルに表示されるようになった。これにより、データフローの確認が視覚的になり、調査時間が大幅に減った。

## CSS Peeperでデザインの色・フォントを抽出
デザインの参照時に、画面上の色コードやフォントサイズを手動で eyedropperツールを使って取っていた。毎回ツールを切り替えるのが面倒だった。
```json
{
  "format": "hex",
  "includeFont": true,
  "copyOnClick": true
}
```
オプションで出力フォーマットをhexにし、フォント情報を含め、クリック時に自動クリップにコピーするように設定した。これでページ上の任意の要素をクリックすると、色コードとフォント名がすぐに取得でき、デザインの実装がスムーズになった。

## Page Ruler Reduxでピクセル単位の測定がすぐできる
レイアウト調整で、要素の間隔やサイズを測るときにスクリーンショットを取って画像編集ソフトで測っていた。手順が多く、細かい調整に時間がかかっていた。
```json
{
  "showGuides": true,
  "snapToElements": true,
  "unit": "px"
}
```
拡張機能の設定でガイド表示と要素へのスナップ、単位をピクセルに設定すると、ツールバーのアイコンをクリックするだけで画面上に測定尺が表示され、ドラッグで長さを取得できるようになった。これにより、レイアウト調整が瞬時に行えるようになり、デザインの微調整が楽になった。

## Clear Cacheでワンクリックキャッシュクリア
開発中にCSSやJSの変更が反映されず、毎回開発者ツールのキャッシュクリアメニューを辿っていた。手順を覚えるのに時間がかかっていた。
```json
{
  "autoClear": false,
  "clearOnReload": true,
  "notify": true
}
```
オプションでページリロード時に自動でキャッシュをクリアし、通知を有効にすると、ツールバーのアイコンをクリックするだけでキャッシュがクリアされるようになった。これで変更の確認が即座にでき、開発のイライラが解消された。

## Session Buddyでタブ・ウィンドウのセッションを保存復元
複数のプロジェクトを行き来するとき、ブラウザを閉じるたびに開いていたタブをもう一度手で開いていた。セッションの保存がなく、作業の中断がストレスだった。
```json
{
  "autoSaveInterval": 5,
  "excludeUrls": ["chrome://*", "edge://*"],
  "notifyOnSave": true
}
```
設定で5分間隔の自動保存と、特定のURLを除外し、保存時に通知を出すようにした。これでブラウザを閉じても、以前のタブ群をワンクリックで復元でき、作業の中断がほぼなくなった。これにより、タスク間の切り替えがストレスフリーになった。

## まとめ
これらの拡張機能は、毎日のちょっとした手間を解消し、開発フローをスムーズにしてくれた。まずはひとつだけでもインストールして、実際の作業時間がどう変わるか試してみてほしい。
