## Vercelでフロントエンドのデプロイが楽になった

Next.jsやReactのアプリをVPSにデプロイする際、ビルド設定やSSL証明書の手配に毎回苦労していました。コードを書いた後にサーバー側で作業するのが面倒で、リリースを先延ばしにすることもありました。

```bash
npx vercel --prod
```

このコマンドを実行するだけで、GitHubと連携したプレビューURLが発行され、本番環境にも即座に反映されます。SSL証明書も自動で発行されるため、HTTPS対応を自分で行う必要がなくなりました。デプロイにかかっていた時間が数分に短縮され、開発に集中できるようになりました。

## Netlifyで静的サイトとフォームを一元管理

静的サイトを公開する際、お問い合わせフォームの処理を別のサービスで用意していました。サーバー側のプログラムを書く知識がなく、フォーム送信の仕組みを作るのに時間をかけていました。

```bash
netlify deploy --prod --dir=public
```

Netlifyにドラッグ＆ドロップするだけでも公開できますが、CLIを使うとコマンド1つで本番環境に反映できます。フォーム機能も無料枠で利用でき、バックエンドを書かずに送信データを受け取れるようになりました。インフラ構築の手間が大幅に減りました。

## Firebase Hostingでシングルコマンド配信

フロントエンドとバックエンドを別々のサーバーで管理しており、デプロイ手順がバラバラでした。ホスティング設定を毎回手で行うのが負担になっていました。

```bash
firebase deploy --only hosting
```

Firebase CLIをインストールして初期化した後、このコマンドを打つだけでホスティングに反映されます。CDNによる高速配信も無料枠で利用でき、SSL設定も自動です。プロジェクト全体を一つのコマンドで公開できるようになり、ミスが減りました。

## GitHub Pagesでポートフォリオを無料公開

ポートフォリオサイトを公開したいけれど、サーバー代を払いたくありませんでした。無料枠のあるサービスを探していましたが、設定が複雑そうで手が出せませんでした。HTMLファイルを置くだけで公開できる方法を探していました。

GitHubリポジトリの設定画面からGitHub Pagesを有効化し、以下のようにプッシュするだけです。

```bash
git push origin main
```

リポジトリにHTMLファイルを置くだけで公開でき、カスタムドメインも無料で設定できました。サーバー管理の知識がなくても、数分でサイトをインターネットに公開できたのが大きな変化です。今ではポートフォリオを気軽に更新できています。

## RenderでAPIサーバーを無料で24時間運用

Node.jsで作った小さなAPIサーバーを動かす場所がありませんでした。VPSを契約するほどの予算はなく、24時間稼働させる方法に悩んでいました。

```yaml
services:
  - type: web
    name: my-api
    env: node
    buildCommand: npm install
    startCommand: npm start
```

`render.yaml` をリポジトリに配置し、GitHubと連携するだけでデプロイできます。無料枠ではスリープしますが、個人開発やポートフォリオには十分です。サーバー構築を意識せずにAPIを公開できるようになりました。

## Railwayでデータベース付きアプリを即デプロイ

データベース付きのアプリを動かすには、サーバーとDBを別々に用意する必要があり、設定が複雑でした。接続情報の管理にも手間がかかっていました。

```bash
railway login
railway up
```

Railway CLIを使うと、コマンド2つでアプリとデータベースを同時にデプロイできます。環境変数もダッシュボードから簡単に設定でき、接続情報の管理が楽になりました。インフラ構築にかかっていた時間を削減できました。

## Cloudflare Pagesで高速なエッジ配信

世界中からアクセスされるサイトを作りたいけれど、サーバーの場所を気にするのが面倒でした。配信速度を上げるための設定に詳しくありませんでした。

```bash
wrangler pages deploy ./public
```

Cloudflare PagesにGitHubを連携するか、Wrangler CLIでデプロイすると、Cloudflareのエッジネットワーク上でサイトが配信されます。無料枠でも十分な帯域が利用でき、SSL設定も自動です。ユーザーの所在地に関わらず高速に表示できるようになりました。

## Supabaseでバックエンド構築を省略

バックエンドAPIを自分で構築する時間がなく、データベースや認証機能を作るのに苦労していました。サーバーサイドの知識が不足していると感じていました。

```bash
supabase login
```

Supabase CLIでログイン後、ダッシュボードからプロジェクトを作成します。データベース、認証、ストレージが無料枠で利用でき、フロントエンドからSDKを使ってデータ操作が可能です。バックエンドをゼロから書く必要がなくなり、開発スピードが上がりました。

## PythonAnywhereでPythonアプリをブラウザから動かす

Python製の小さなWebアプリを動かす場所がありませんでした。サーバー上でPython環境を構築するのに自信がなく、デプロイを断念していました。ブラウザだけで完結する方法を探していました。

ブラウザ上の管理画面でWebアプリを設定し、コンソールから以下のように依存関係をインストールします。

```bash
pip install -r requirements.txt
```

WSGIファイルの設定を行うだけで、Pythonアプリを公開できます。無料枠でも十分な機能が使え、サーバー構築の知識がなくても動かせるようになりました。Python初心者にもおすすめのサービスです。

## Fly.ioでコンテナアプリをグローバル展開

Dockerでアプリを動かしたいけれど、インフラ構築が難しくて手が出せませんでした。コンテナオーケストレーションの知識がなく、デプロイを躊躇していました。

```bash
fly launch
fly deploy
```

Fly CLIをインストールして `fly launch` を実行すると、対話形式でアプリ設定が作成されます。`fly deploy` でグローバルにデプロイでき、SSL証明書も自動発行されます。Dockerfileがあれば、インフラの詳細を気にせずにアプリを世界中で動かせるようになりました。

## まとめ

個人開発で使える無料ホスティングサービスを10個紹介しました。どれも無料枠で十分に使えるものばかりです。インフラ構築に時間を取られていた頃の自分にとって、これらのサービスは開発のハードルを大きく下げてくれました。サーバーの契約やSSL設定に悩む必要がなくなり、コードを書くことに集中できるようになりました。駆け出しエンジニアの方も、まずは気になるサービスを1つ選んで、小さなアプリを公開してみてください。公開の喜びが、次の開発へのモチベーションになるはずです。
