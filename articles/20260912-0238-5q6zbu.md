本文: SQLはリレーショナルデータベース（RDB）と対話するための言語であり、エンジニアであれば業務のどのフェーズでも触れることになる技術です。データの抽出・集約・結合から、分析・レポーティングまで、SQLを使いこなせるかどうかは開発の生産性に直結します。ここでは、実務で最も頻繁に登場する SELECT / WHERE / JOIN の基本から、集計関数やサブクエリまで、具体的なコード例を交えながら解説します。

## 1. SELECT / WHERE / JOIN の基本

SQL の中核をなすのは「データを取り出す SELECT 文」です。まずは最もシンプルなクエリから始めましょう。

```sql
-- 全従業員の名前と部署を取得
SELECT name, department
FROM employees;
```

WHERE 句を使うと、条件に一致する行だけを抽出できます。

```sql
-- 部署が 'Sales' の従業員だけを取得
SELECT name, salary
FROM employees
WHERE department = 'Sales';
```

複数の条件を組み合わせる場合は AND / OR を使います。

```sql
-- 部署が 'Sales' で、かつ給与が 500000 以上の従業員
SELECT name, salary
FROM employees
WHERE department = 'Sales' AND salary >= 500000;
```

JOIN は複数のテーブルを紐づけてデータを統合する機能です。実務では単一テーブルだけで完結するクエリは少なく、必ず隣接テーブルと結合する場面が訪れます。

```sql
-- 従業員テーブルと部署テーブルを紐づけて、部署名も取得
SELECT e.name, d.department_name
FROM employees e
JOIN departments d ON e.department_id = d.id;
```

JOIN には種類があります。INNER JOIN は両方のテーブルに一致するレコードのみを返しますが、LEFT JOIN は左のテーブルの全レコードを保持し、右のテーブルにマッチしない場合は NULL を返します。

```sql
-- 部署に属さない従業員も含めて全員を取得
SELECT e.name, d.department_name
FROM employees e
LEFT JOIN departments d ON e.department_id = d.id;
```

## 2. 集計関数とGROUP BY

実務では「売上総額」「平均年齢」「件数のカウント」など、集計した数値が必要になる場面が多くあります。そのために SQL には集約関数（aggregate function）が用意されています。

- COUNT：件数
- SUM：合計
- AVG：平均
- MAX / MIN：最大値 / 最小値

```sql
-- 従業員の総数を取得
SELECT COUNT(*) AS total_count
FROM employees;

-- 部署ごとの平均給与を取得
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department;
```

GROUP BY は集計の単位を指定する句です。HAVING 句を使うと、集計後の結果に対して条件を絞り込めます（WHERE は集計前に条件を適用するため、グループ単位の絞り込みには HAVING を使います）。

```sql
-- 平均給与が 600000 以上の部署だけを表示
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department
HAVING AVG(salary) >= 600000;
```

ORDER BY で並べ替えも可能です。

```sql
-- 平均給与の降順で表示
SELECT department, AVG(salary) AS avg_salary
FROM employees
GROUP BY department
ORDER BY avg_salary DESC;
```

## 3. サブクエリ

サブクエリは、SELECT 文の中にさらに SELECT 文をネストする構文です。複雑な条件を別のクエリで求め、その結果を元のクエリに渡すときに活用します。

```sql
-- 平均給与以上の給与をもらう従業員を取得
SELECT name, salary
FROM employees
WHERE salary >= (SELECT AVG(salary) FROM employees);
```

FROM 句にサブクエリを置いて一時的なテーブル（派生テーブル）を作ることもできます。

```sql
-- 各部署の平均給与を基準に、自部署の平均以上の給与をもらう従業員を抽出
SELECT e.name, e.salary, e.department
FROM employees e
JOIN (
    SELECT department, AVG(salary) AS dept_avg
    FROM employees
    GROUP BY department
) dept_avg ON e.department = dept_avg.department
WHERE e.salary >= dept_avg.dept_avg;
```

サブクエリは IN 演算子と組み合わせることもよく使われます。

```sql
-- 注文履歴がある顧客だけを取得
SELECT name
FROM customers
WHERE id IN (SELECT customer_id FROM orders);
```

## まとめ

SQL の基本は、SELECT で「何を」、FROM で「どこから」、WHERE で「どんな条件で」、JOIN で「どう結合する」かを定義することです。集計関数と GROUP BY を組み合わせればデータの傾向を把握でき、サブクエリを使えば複雑な条件にも対応できます。いずれも暗記ではなく「なぜそのクエリが必要なのか」を理解しながら、実際のテーブル構造を想像しながら書くことが上達の近道です。日頃の業務で小さなクエリから書き直し、実行計画を確認する習慣をつけると、より実力が定着します。
