## 2. コマンドパレットでメニュー探しが不要になった
**困りごと**  
「設定を開く」「拡張機能をインストール」など、メニュー階層を辿るのに数秒ロスしていた。  
**使い方**  
```text
Ctrl + Shift + P   # Windows / Linux
Cmd + Shift + P    # macOS
```  
**変化**  
目的のコマンドを入力するだけで即実行でき、マウス操作がほぼゼロになった。

## 3. クイックオープンでファイル移動が瞬時に
**困りごと**  
サイドバーのツリーを展開して目的のファイルを探すのに手間取っていた。  
**使い方**  
```text
Ctrl + P   # Windows / Linux
Cmd + P    # macOS
```  
**変化**  
ファイル名の一部を打つだけで開けるため、プロジェクト内の移動が 1 秒以内で完了する。

## 4. 統合ターミナルの表示・非表示がトグルで完結
**困りごと**  
ターミナルを開くたびにメニューから選ぶか、別ウィンドウを立ち上げていた。  
**使い方**  
```text
Ctrl + `   # Windows / Linux / macOS 共通
```  
**変化**  
コードを書きながら即座にコマンドを叩けるようになり、コンテキストスイッチが激減した。

## 5. 定義へジャンプでコードリーディングがスムーズに
**困りごと**  
関数やクラスの定義を探すのに検索や手動スクロールを繰り返していた。  
**使い方**  
```text
F12               # 定義へ移動
Alt + F12         # ピーク定義（インライン表示）
```  
**変化**  
気になった箇所を即座に確認でき、理解度が上がりデバッグ時間が短縮された。

## 6. シンボルリネームで一括リファクタが安全に
**困りごと**  
変数名を変えるたびに検索置換で漏れが出たり、コメントまで書き換わって困っていた。  
**使い方**  
```text
F2   # カーソル位置のシンボルをリネーム
```  
**変化**  
プロジェクト全体の参照箇所が自動更新され、タイポや漏れがゼロになった。

## 7. ドキュメント整形でコードスタイル統一が自動に
**困りごと**  
インデントや改行を手直しするのが面倒で、レビューで指摘されることが多かった。  
**使い方**  
```text
Shift + Alt + F   # Windows / Linux
Shift + Option + F # macOS
```  
**変化**  
保存時自動整形と併用すれば、常に統一スタイルでコミットできるようになった。

## 8. エディタ分割で並行作業がラクに
**困りごと**  
複数ファイルを同時に見るためにウィンドウを複数開き、切り替えにストレスを感じていた。  
**使い方**  
```text
Ctrl + \          # エディタを右に分割
Ctrl + 1 / 2 / 3  # グループ間移動
```  
**変化**  
テストコードと実装を横並びにできるため、往復の手間がなくなり集中力が持続する。

## 9. ワークスペース内検索で影響範囲を即把握
**困りごと**  
grep コマンドを叩くか、ファイルごと開いて検索していた。  
**使い方**  
```text
Ctrl + Shift + F   # Windows / Linux
Cmd + Shift + F    # macOS
```  
**変化**  
キーワード一つで全ファイルのヒット箇所が一覧表示され、リファクタ前の影響調査が数秒で済む。

## 10. Git 変更のステージ・コミットがショートカットで完結
**困りごと**  
ソースコントロールビューを開き、マウスでステージ→コミットメッセージ入力と手順が多かった。  
**使い方**  
```text
Ctrl + Shift + G   # ソースコントロールを開く
Ctrl + Enter       # コミットメッセージ入力後即コミット
```  
**変化**  
キーボードだけで「変更→ステージ→コミット」が流れるようになり、コミット頻度が上がった。

## まとめ
ショートカットを一つずつ体に染み込ませれば、マウスに頼る時間が劇的に減り、思考の流れを止めずにコードへ向き合える。まずは 1 つ試してみてほしい。
