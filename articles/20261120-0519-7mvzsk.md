## Pocket で後読みリストが溜まらない
気になる記事をブラウザタブで開きっぱなしにして、後で読むつもりが忘れることが多かった。Pocket のブラウザ拡張でワンクリック保存し、タグ「後で読む」を付ける運用にした。  
```json
{
  "url": "https://example.com/article",
  "tags": ["後で読む", "React"]
}
```  
オフラインでも読め、タグ検索で目的の記事に即アクセスできるようになった。

## GitHub Trending の通知を Slack に流す
トレンドリポジトリを毎日手動でチェックしており、時間が取れない日は見逃していた。GitHub Actions で毎日午前 8 時に Trending API を叩き、Slack Webhook へ投稿するワークフローを組んだ。  
```yaml
- name: Fetch Trending
  run: |
    curl -s https://ghapi.huchen.dev/repositories?language=typescript > trending.json
- name: Post to Slack
  uses: slackapi/slack-github-action@v1.23.0
  with:
    payload: ${{ steps.fetch.outputs.trending }}
```  
朝の Slack 見るだけで注目リポジトリが把握でき、星付けやフォークの判断が速くなった。

## Twitter Lists でノイズを減らし専門情報だけ追う
タイムラインが雑多で、技術ツイートが埋もれていた。専門分野ごとに List を作り、リスト専用の通知を ON にした。  
```text
# リスト作成手順（Web UI）
1. プロフィール → Lists → Create new list
2. 名前: "Frontend Experts"
3. 追加したいアカウントを検索して追加
```  
リストを開くだけで関連ツイートだけが流れ、情報収集の精度が上がった。

## Dev.to のニュースレターをメールで受け取る
記事を探しに行く手間を省きたいと思い、Dev.to の設定で「Weekly digest」を有効にした。  
```text
Settings → Emails → Weekly digest → ON
```  
毎週月曜にまとめが届き、気になるタイトルだけクリックすれば良くなった。

## Hacker News の「Ask HN」を RSS で購読
質問スレッドから実践的なノウハウを得たかったが、サイト巡回が面倒だった。HN の公式 RSS（`https://hnrss.org/ask`）を Feedly に追加した。  
```xml
<feed>
  <title>Ask HN</title>
  <link>https://hnrss.org/ask</link>
</feed>
```  
新着質問が即座にフィードに現れ、解決策をストックしやすくなった。

## Zenn の「フォロー中タグ」通知を LINE Notify に転送
Zenn で特定タグの新着を逃さずキャッチしたかった。Zenn の設定でタグをフォローし、Webhook を LINE Notify へ向けた。  
```bash
curl -X POST https://notify-api.line.me/api/notify \
  -H "Authorization: Bearer ${LINE_TOKEN}" \
  -F "message=新着: ${ZENN_TITLE} ${ZENN_URL}"
```  
スマホに通知が来るため、移動中でもチェックできるようになった。

## Qiita の「ストック」を Notion に自動同期
後で見返したい記事を Qiita でストックしていたが、検索性が低かった。GitHub Actions で毎日 Qiita API を叩き、Notion データベースへ追加するフローを作った。  
```yaml
- name: Sync Qiita Stocks
  run: |
    python sync_qiita_to_notion.py --token ${{ secrets.QIITA_TOKEN }} --notion ${{ secrets.NOTION_TOKEN }}
```  
Notion でタグ・日付でフィルタでき、知識ベースとして活用できるようになった。

## Reddit r/programming の「Hot」を RSS で取得
Reddit のホット投稿をブラウザで見るのが億劫だった。`https://www.reddit.com/r/programming/hot/.rss` を Feedly に登録した。  
```text
Feedly → Add Content → Paste URL → Follow
```  
主要な議論やツール紹介が自動で流れ、トレンド把握が楽になった。

## TLDR Newsletter をメールで購読
毎朝複数のニュースレターを開くのが負担だった。TLDR の無料メール購読を有効にし、1 通で主要技術ニュースを要約してもらうようにした。  
```text
https://tldr.tech/signup → Enter email → Confirm
```  
朝 5 分で全体像を掴め、詳細が気になるリンクだけ深掘りできるようになった。

## まとめ
情報収集の手間を自動化・一元化するだけで、毎日のインプットが劇的に効率化される。まずは 1 つ試してみてほしい。
