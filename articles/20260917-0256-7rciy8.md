## 前提：AIツールの強みと弱みを知る

AIツールは以下の場面で強力です。
- コードの雛形作成
- テストケースの生成
- エラーメッセージの解説
- ドキュメントの翻訳・要約

一方で、以下の場面では注意が必要です。
- ビジネスロジックの正確性の保証
- セキュリティ上の境界線の判断
- パフォーマンスチューニングの最終判断

つまり、「AIは良いアイデアを出してくれるが、最終責任は常に自分にある」という認識が前提になります。

## 聞き方のコツ：プロンプトを「料理のレシピ」にする

AIにうまく結果を出すには、プロンプト（指示文）の質が重要です。ここでは「料理のレシピ」に例えて考えます。

### ❌ 悪い例：曖昧な依頼

```
Reactでいい感じのフォームを作って
```

この指示だと、AIは「いい感じ」の定義がわからず、意図しない実装を返すことがあります。

### ✅ 好的例：条件を明示する

```
React + TypeScriptで、メールアドレスとパスワードのログインフォームを作成してください。
以下の条件を満たしてください：
- バリデーションはZodで行う
- エラーメッセージは日本語で表示
- Tailwind CSSでスタイリング
- テストコードはJestで書く
```

このように、「技術スタック」「出力形式」「制約条件」を明示することで、AIの出力の精度が大幅に上がります。

### 実践のコツ：「段階的に聞く」

いきなり完成コードを求めるのではなく、以下のように段階的に聞くと、AIとの対話が効率的です。

1. まずアーキテクチャを聞く
2. 次に具体的な実装を聞く
3. 最後にテストケースを依頼する

この流れで書くことで、自分の理解も深まり、AIの出力を検証しやすくなります。

## コードを自分で書く部分との使い分け

AIツールを使う上で最も重要なのは、「何をAIに任せて、何を自分で書くか」の境界線を持つことです。

### 自分で書くべき部分

- ビジネスロジックの核心部分
- セキュリティに関する判定
- パフォーマンスが重要なループ処理

### AIに任せて良い部分

- テストコードの雛形
- SQLのJOIN文や条件分岐
- コメントやドキュメントの翻訳

### 具体例：認証機能の実装

以下は、AIツールと自分の書き分けを意識した例です。

```typescript
// 自分で書く：ビジネスロジックの核心
interface AuthResult {
  success: boolean;
  userId?: string;
  error?: 'INVALID_CREDENTIALS' | 'ACCOUNT_LOCKED';
}

// AIに生成を依頼：バリデーション部分
// ※AIの出力を必ずレビューしてから採用
const validateLoginInput = (email: string, password: string) => {
  // AIが生成した正規表現をそのまま使うのではなく、
  // 自分で動作を確認してから採用する
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!emailRegex.test(email)) {
    throw new Error('Invalid email format');
  }
  if (password.length < 8) {
    throw new Error('Password must be at least 8 characters');
  }
  return { email, password };
};
```

このように、「核心は自分で、補助はAI」という使い分けが重要です。

## よくある失敗と対策

### 失敗1：AIの出力をパッと見で信用する

対策：必ず「なぜこの実装にしているのか」を自分で説明できるか確認する。説明できない部分は調べるか、AIに再質問する。

### 失敗2：AIに全体を任せきりにする

対策：まずは小さな関数や単体テストからAIを使ってみる。全体の設計は自分で考える。

### 失敗3：エラーが出たらAIに丸投げする

対策：エラーメッセージを読み、自分でも原因を推測してからAIに相談する。「自分の推測とAIの回答のどちらが正しいか」を比較する訓緗が成長につながる。

## まとめ：AIツールは「スキルを高めるための道具」

AIツールは開発速度を上げてくれますが、それは「自分のスキルがある前提で」こそ効果を発揮します。駆け出しエンジニアのうちは、AIの出力を「正解」ではなく「提案」として受け取り、必ず自分の目で確認する習慣をつけましょう。

最終的には、AIツールを使えるようになることよりも、「AIを使える人材になること」が重要です。そのためには、基礎的なプログラミングスキルを磨き続けることが不可欠です。
