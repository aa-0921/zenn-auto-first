## freeCodeCamp で体系的なカリキュラムを無料で進められる
独学だと「何をどの順番で学べばいいか」がわからず、途中で挫折しがちだった。freeCodeCamp の CLI ツールを使えば、ローカルで課題を実行・テストできる。
```bash
npx @freecodecamp/cli@latest start
```
カリキュラムが段階的に組まれているため、基礎から応用まで抜け漏れなく習得できた。

## Progate でスライド形式のハンズオンがすぐ始められる
環境構築に時間を取られ、コードを書く前に挫折していた。Progate はブラウザ上でエディタと実行環境が一体化しており、ログイン後すぐにレッスンを開始できる。
```bash
# ブラウザで https://prog-8.com にアクセスし、ログインするだけ
```
スライドを見ながらその場でコードを書けるため、概念理解から実装まで一気に進められた。

## Dotinstall で 3 分動画を繰り返し視聴できる
長い講義動画だと集中が切れ、復習しにくかった。Dotinstall は 1 本 3 分程度の動画で、コマンドラインから再生リストを取得できる。
```bash
curl -s https://dotinstall.com/api/v1/lessons | jq '.[] | select(.title | contains("Git"))'
```
短い動画を繰り返し見ることで、細かいコマンドオプションまで定着した。

## Udemy「JavaScript 完全ガイド」で実務レベルのプロジェクトを体験できる
断片的な知識しかなく、実務で通用するコードが書けなかった。Udemy のコースはセクションごとに完成品リポジトリが提供され、クローンしてすぐ動かせる。
```bash
git clone https://github.com/udemy-js-complete-guide/project-starter.git
cd project-starter && npm install && npm run dev
```
実際に動くアプリを触りながら学べたため、デバッグやリファクタリングの感覚が身についた。

## Coursera「Algorithms, Part I」で基礎アルゴリズムを体系的に学べる
競技プログラミングの問題を解くたびに、アルゴリズムの選択に迷っていた。Coursera の講義は週ごとに課題が出され、自動採点で即座にフィードバックが得られる。
```bash
# 講義内で提供される Java スケルトンをダウンロードし、ローカルでコンパイル
javac Percolation.java && java Percolation
```
理論と実装をセットで学べたおかげで、問題を見た瞬間に適切なアルゴリズムが浮かぶようになった。

## Qiita で現場のノウハウを検索・ストックできる
公式ドキュメントだけでは「なぜこの書き方が推奨されるか」がわからなかった。Qiita の記事はタグ検索とストック機能で、後から見返しやすい。
```bash
# Qiita CLI でタグ「React」の最新記事を取得
qiita list --tag React --limit 10 --format json
```
実務で直面したエラーの解決策が即座に見つかり、ストックしておけば再検索の手間がなくなった。

## Zenn で技術記事を公開しながら学習を振り返れる
学んだことをアウトプットせず、知識が定着しないことが多かった。Zenn は Markdown で記事を書き、GitHub 連携で自動デプロイできる。
```bash
npx zenn new:article --slug learning-review
# 記事を書き、git push するだけで公開完了
```
書く過程で理解が深まり、後から自分の記事を見返すだけで復習が完結するようになった。

## GitHub Learning Lab で実践的な Git/GitHub 操作を演習できる
チーム開発でブランチ戦略や PR の運用が曖昧で、コンフリクト解消に時間を取られていた。Learning Lab はリポジトリを用意し、ボットがステップごとに指示を出してくれる。
```bash
# GitHub UI から「Learning Lab」→「GitHub Flow」を開始
# 指示に従い、ブランチ作成・コミット・PR 作成を実施
```
実際のリポジトリ上で手順を体験できるため、現場で即戦力として Git 操作ができるようになった。

## AtCoder でアルゴリズム力を競プロ形式で鍛えられる
理屈だけでは実装スピードが上がらず、本番で時間切れになることが多かった。AtCoder は毎日開催されるコンテストと過去問アーカイブで、実戦感覚を養える。
```bash
# ローカルでテストケースを実行するスクリプト例
g++ -std=c++17 main.cpp -o main && ./main < sample1.in
```
定期的に参加することで、制約条件を読み解く速度と実装の正確さが劇的に向上した。

## まとめ
紹介した 10 のサイト・教材は、それぞれ「何に困っていたか」を解決する具体的な機能を持っている。まずは気になった 1 つを試してみて、自分の学習スタイルに合うか確認してほしい。
