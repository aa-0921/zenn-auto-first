## REST APIとは何か、なぜ使うのか

REST（Representational State Transfer）は、Webサービス間の通信に特化したアーキテクチャです。HTTPプロトコルを使って、クライアントとサーバーがリソースをやり取りする仕組みです。特に、フロントエンドとバックエンドが分離されたWebアプリケーションでは、REST APIを通じてデータを送受信することが一般的です。  

たとえば、ユーザーが投稿機能を使う際、フロントエンドからサーバーにデータを送信すると、そのデータはJSON形式でREST API経由で保存されます。このプロセスでは、HTTPメソッド（GET、POSTなど）とステータスコード（200、404など）の理解が不可欠です。

## HTTPメソッドの基本：GET、POST、PUT、DELETE

REST APIでは、リソースに対する操作を5つのHTTPメソッドで表現します。以下に代表的なメソッドを解説します。

### GETメソッド：データの取得
GETは「リソースを取得する」操作に使います。たとえば、ユーザー一覧を取得する場合、以下のように呼び出します。
```javascript
fetch('https://api.example.com/users')
  .then(response => response.json())
  .then(data => console.log(data));
```
このコードでは、`fetch`でGETリクエストを送信し、レスポンスをJSONに変換して処理します。GETはデータの可視性を保つため、キャッシュや履歴上の記録が可能です。

### POSTメソッド：データの送信
POSTは「リソースを作成する」操作に使います。たとえば、新しい投稿を送信する場合：
```javascript
fetch('https://api.example.com/posts', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'サンプル投稿' })
})
  .then(response => response.json())
  .then(data => alert('投稿成功！'));
```
ヘッダーに`Content-Type: application/json`を指定し、JSON形式のデータを送信します。POSTは副作用を生じるため、キャッシュされません。

### PUTメソッド：データの更新
PUTは「既存リソースを完全更新」する操作です。たとえば、ユーザー情報の修正：
```javascript
fetch('https://api.example.com/users/1', {
  method: 'PUT',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: '新しい名前' })
})
  .then(response => response.status);
```
レスポンスのステータスコード（200、404など）で結果を確認します。

### DELETEメソッド：データの削除
DELETEは「リソースを削除する」操作です。たとえば、投稿を削除する場合：
```javascript
fetch('https://api.example.com/posts/5', {
  method: 'DELETE'
})
  .then(response => response.ok ? '削除成功' : '削除失敗');
```
DELETEはGETと同様、キャッシュや履歴上の記録が可能です。

## ステータスコードで結果を判断する

HTTPレスポンスには、APIの結果を示すステータスコードが含まれます。以下に重要なコードを示します。

- **200 OK**：リクエスト成功
- **400 Bad Request**：リクエストの形式が不正
- **404 Not Found**：リソースが見つからない
- **500 Internal Server Error**：サーバー側のエラー

たとえば、404エラーの場合、フロントエンドではユーザーに親切なメッセージを表示すべきです。
```javascript
fetch('https://api.example.com/invalid')
  .then(response => {
    if (!response.ok) throw new Error('リソースが見つかりません');
    return response.json();
  })
  .catch(error => console.error(error));
```

## JSONデータの扱い方：送信と受信の流れ

REST APIでは、データフォーマットとしてJSONが普遍的に使用されます。JSONはキーと値のペアで構造化されたデータを表現します。JavaScriptでは、`json()`メソッドでレスポンスをパースし、`stringify()`メソッドでデータを送信します。

### JSONの構造例
```json
{
  "id": 1,
  "title": "サンプル投稿",
  "author": "ユーザー名"
}
```
この構造をJavaScriptオブジェクトに変換するには：
```javascript
const data = { id: 1, title: 'サンプル' };
const jsonData = JSON.stringify(data); // 送信用
const parsedData = JSON.parse(jsonData); // 受信用
```

### fetchとaxiosの比較
- **fetch**：ブラウザに標準搭載され、シンプルなGET/POSTに適する
- **axios**：エラーハンドリングが直感的で、サーバーサイドでも利用可能

axiosの例（GET）：
```javascript
axios.get('https://api.example.com/users')
  .then(response => console.log(response.data))
  .catch(error => console.error(error.response));
```

## まとめ

REST APIは、HTTPメソッドとJSONを組み合わせて、フロントエンドとバックエンドが連携する仕組みです。GET/POST/PUT/DELETEの使い分けや、200/404/500などのステータスコードを理解することで、APIの挙動を正しく扱うことができます。`fetch`や`axios`を使ったコード例を実践することで、実際の開発で役立つスキルが身につきます。  

始めたばかりのエンジニアは、まずは簡単なAPIを呼び出すことから始めて、徐々に複雑な操作に挑戦してください。REST APIの理解は、フルスタック開発の基盤となる重要な知識です。
