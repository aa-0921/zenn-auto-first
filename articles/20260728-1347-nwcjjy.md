## 2. ルーティングエラーのデバッグ

### 2.1 よくあるパターン

- `No route matches [GET] /users/123` のようなエラー
- `Ambiguous route` が出力される

### 2.2 デバッグ手順

1. `rails routes` で定義されているルート一覧を確認
2. `config/routes.rb` の優先順位や制約をチェック
3. `match` と `get` の使い分けを明確に

```ruby
# config/routes.rb
Rails.application.routes.draw do
  resources :posts do
    collection do
      get 'search', to: 'posts#search' # 検索用ルート
    end
  end

  # ネストされたリソースの定義
  namespace :admin do
    resources :articles
  end

  # デフォルトの root
  root to: 'home#index'
end
```

### 2.3 実践例

```bash
$ rails routes | grep users
   user GET    /users/:id(.:format)   users#show
   user DELETE /users/:id(.:format)   users#destroy
```

上記のように `rails routes` の出力を確認すれば、期待したパスが生成されているかすぐに判別できます。
