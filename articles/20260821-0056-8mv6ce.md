## Chrome DevToolsでDOM状態を瞬時に確認できる
同じ要素のクラスが動的に変わるケースで、手作業でHTMLをチェックしていた。`$0` で現在選択した要素を取得し、`getComputedStyle` でスタイルを確認。  
```javascript
$0.getAttribute('class')
getComputedStyle($0).color
```  
これで、何が変わったかを即座に把握でき、デバッグ時間を半分に短縮できた。

## ソースマップで圧縮後のコードをデバッグ
ビルド後のバンドルが圧縮され、行番号がずれたためデバッグが困難だった。`sourceMap: true` を設定し、DevToolsで元のソースにマッピング。  
```javascript
// vite.config.js
export default defineConfig({
  build: { sourcemap: true }
})
```  
元コードの行番号でエラーを即座に特定できた。

```bash
// vite dev で起動
```  
作業効率が大幅に向上し、試行 Fault のサイクルが短縮された。

## axe-coreで自動アクセシビリティテスト
アクセシビリティのチェックを手作業で行い、時間がかかっていた。axe-coreをCLIで実行し、レポートを自動生成。  
```bash
npx axe-core http://localhost:3000 > axe-report.html
```  
問題箇所がすぐに分かり、修正がスムーズになった。
