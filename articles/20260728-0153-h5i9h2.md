## 開発効率を上げるおすすめ拡張機能

### 必須のベーシック拡張機能

以下はすべてのプロジェクトで役立つ基本的な拡張機能です。

- **Japanese Language Pack for VS Code**: 日本語インターフェースで操作でき、公式ドキュメントも日本語化されます。
- **Bracket Pair Colorizer**: 対応する括弧を色で視覚化し、ネストが深いコードの可読性を向上させます。
- **Auto Rename Tag**: 開始タグを編集すると自動で終了タグも変更してくれます。
- **Path Intellisense**: ファイルパスを入力中に自動補完候補を表示します。
- **Prettier**: コードを自動整形し、チーム内のコードスタイルを統一できます。

```json
// settings.json に追加すると Prettier がデフォルトで有効になります
{
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.formatOnSave": true
}
```

### 言語・フレームワーク別の拡張機能

使用する技術スタックに応じて以下の拡張機能を追加すると効果的です。

- **ESLint / Prettier**: JavaScript/TypeScript プロジェクトでコード品質を保ちます。
- **Volar**: Vue.js 開発用の公式拡張機能で、型安全なコンポーネント開発をサポートします。
- **Tailwind CSS IntelliSense**: Tailwind CSS のクラス名をリアルタイムで補完します。
- **GitLens**: Git の履歴や blame 情報をエディタ上で確認でき、コードレビューが容易になります。

## キーバインドで開発速度をアップ

VS Code のキーバインドを活用することで、マウス操作を減らし開発速度を向上させることができます。以下はよく使うショートカットです。

| ショートカット | 機能 |
|---|---|
| `Ctrl + P` | ファイル名で検索して開く |
| `Ctrl + Shift + P` | コマンドパレットを開く |
| `Ctrl + Shift + E` | エクスプローラーにフォーカス |
| `Ctrl + Shift + F` | プロジェクト内検索 |
| `Ctrl + Shift + G` | Git パネルを開く |
| `Ctrl + Shift + D` | デバッグパネルを開く |
| `Ctrl + Shift + O` | シンボル（関数名など）でジャンプ |

### キーバインドのカスタマイズ

デフォルトのキーバインドでは物足りない場合は、`keybindings.json` でカスタマイズできます。例えば、`Ctrl + Shift + V` で Markdown プレビューを開く設定は以下の通りです。

```json
[
  {
    "key": "ctrl+shift+v",
    "command": "markdown.showPreview",
    "when": "editorTextFocus"
  }
]
```

## 設定の共有方法

チーム内で同じ開発環境を共有することは、コードレビューやデバッグの効率を大きく向上させます。VS Code では以下の方法で設定を共有できます。

### 1. ワークスペース設定（`.vscode/settings.json`）

プロジェクトルートに `.vscode/settings.json` を配置すると、そのプロジェクト専用の設定が適用されます。チームメンバーがリポジトリをクローンするだけで、自動的に設定が反映されます。

```json
{
  "editor.tabSize": 2,
  "files.exclude": {
    "**/.git": true,
    "**/node_modules": true
  },
  "search.exclude": {
    "**/dist": true
  }
}
```

### 2. 拡張機能の共有

必要な拡張機能をチームで共有するには、`.vscode/extensions.json` ファイルを使用します。

```json
{
  "recommendations": [
    "esbenp.prettier-vscode",
    "bradlc.vscode-tailwindcss",
    "github.vscode-pull-request-github"
  ]
}
```

このファイルをリポジトリにコミットしておくと、新しいメンバーがプロジェクトを開いたときに必要な拡張機能のインストールを促す通知が表示されます。

### 3. 個人設定のバックアップ

個人の VS Code 設定は `~/.vscode/extensions.json` や `settings.json` に保存されています。これを Git で管理することで、異ないるマシン間で設定を同期できます。

```bash
# 設定ファイルの場所（macOS）
~/Library/Application\ Support/Code/User/

# 設定ファイルの場所（Windows）
%APPDATA%\Code\User\
```

## まとめ

VS Code の拡張機能と設定は開発効率を大きく左右する要素です。特に以下の点を押さえておけば、チーム開発や個人開発で大きなメリットを得られます。

- **ベーシック拡張機能**（Prettier, Path Intellisense など）を導入する
- **キーバインド**を活用してマウス操作を減らす
- **ワークスペース設定**と**拡張機能の共有**でチーム開発を効率化する

これらの設定をプロジェクトごとに最適化していくことで、長い目でみて開発速度とコード品質の向上につながります。ぜひ今日から一つずつ試してみてください。
