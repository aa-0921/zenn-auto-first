同じ HTML ファイルを何度も手動でリロードして確認作業に疲れていました。ページ更新後もコンソールエラーに気づかず、フォーマットもバラバラで、コードは見づらいまま。VS Code 拡張機能を追加することで、これらの日常的な手間が一気に解決されました。ここでは、個人的に愛用している 10 個の拡張機能を紹介し、それぞれの導入前後の変化を詳しく説明します。

## Live Server でページ確認が自動更新に
ブラウザを開かずに HTML/CSS/JS を即時反映させたいと思っていました。`Live Server` 拡張機能をインストールし、`npx live-server` を実行するだけで、ローカルサーバーが立ち上がり、編集と同時にページが更新されます。コンソールエラーも即座に確認でき、手動リロードのストレスから解放されました。

```json
{
  "command": "npx live-server"
}
```

## Prettier でコード整形がワンタッチに
コードの書式がプロジェクトごとにバラバラで、コミット時に毎回手直ししていました。`Prettier - Code formatter` を追加し、`npm install prettier -D` と `Ctrl+Shift+P` → `Prettier: Format Code` を実行すると、ファイルが自動整形されます。フォーマットに関する議論が減り、コードレビューがスムーズになりました。

```bash
npm install prettier -D
```

## ESLint 拡張機能でタイポを即座に検出
スペルミスや構文エラーがリリース後に発覚し、修正に時間がかかっていました。`ESLint` 拡張機能を有効にし、`npm install eslint -D` と `Ctrl+Shift+P` → `ESLint: Fix All` を実行すると、入力と同時に問題がハイライトされます。デバッグ時間が大幅に短縮されました。

```bash
npm install eslint -D
```

## Bracket Pair Colorizer 2 でネスト構造が一目瞭然
同じタグを何度も探してしまい、ファイルがごちゃごちゃ見えていました。`Bracket Pair Colorizer 2` をインストールすると、異なるネストレベルが色分け表示されます。`Ctrl+Shift+P` → `Bracket Pair Colorizer: Toggle` で有効化です。コードの可読性が劇的に向上しました。

```json
{
  "command": "Toggle Bracket Pair Colorizer"
}
```

## indent-Ruler でインデント位置が明確に
インデントのずれに気づくのが遅れ、レイアウト崩れを何度も修正していました。`indent-Ruler` を追加し、`Ctrl+Shift+P` → `indent-Ruler: Toggle` を実行すると、インデント位置が視覚的に強調されます。コード編集がより直感的になりました。

```json
{
  "command": "Toggle indent-Ruler"
}
```

## Path Intellisense でインポートパスが自動補完
`./../components/Button` のようなパスを手入力していたら、タイプミスが多発していました。`Path Intellisense` をインストールし、`Ctrl+Space` で補完を表示すると、正しいパスが提案されます。インポート作業が3分の1の時間で行えるようになりました。

```json
{
  "command": "Trigger Path Intellisense"
}
```

## GitHub Markdown Preview でマークダウン確認が迅速に
`.md` ファイルをエディタで開き、別ブラウザで確認する必要があり、作業の流れが分断されていました。`GitHub Markdown Preview` をインストールすると、`Ctrl+Shift+M` で即座にプレビューが表示されます。マークダウン編集がスムーズになり、ブランチ切り替えも減りました。

```json
{
  "command": "Open Markdown Preview"
}
```

## TODO Tree で残タスクが一目瞭然に
TODO コメントをファイルごとに探していたら、見落としが多発していました。`TODO Tree` を追加し、`Ctrl+Shift+T` でツリーを表示すると、プロジェクト全体の未完了項目が一覧化されます。タスク管理が効率化され、納期前の panicked 状態が減りました。

```json
{
  "command": "Toggle TODO Tree"
}
```

## Debugger for Chrome でNode.jsデバッグが簡単に
`console.log` だらけのデバッグ作業が長引き、原因特定に苦労していました。`Debugger for Chrome` をインストールし、`Ctrl+Shift+D` でデバッガーを起動すると、ブレークポイント設定や変数の監視が直接行えます。デバッグ時間が半分以下になりました。

```json
{
  "command": "Open Debugger"
}
```

## Code Runner でワンクリック実行が実現
ファイルを実行するたびにターミナルを開き、コマンドを入力する手間がありました。`Code Runner` を使えば、`Ctrl+Shift+R` で現在のファイルが即座に実行されます。結果がエディタ上に表示され、実行環境の切り替えも簡単です。開発サイクルの回転が速くなりました。

```json
{
  "command": "Run Code"
}
```

## まとめ
これらの拡張機能は、些細な手作業を自動化し、開発体験を大きく変えてくれました。まずは1つ、Live Server または Code Runner から試して、VS Code ライフの向上を実感してみてください。
