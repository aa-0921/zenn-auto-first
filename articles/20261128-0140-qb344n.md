同じコマンドを毎回ターミナルに手で打ち、ウィンドウはマウスでちまちま動かし、コピーした文字列を探すのに何度も履歴をたどる。入社して最初の頃は、そんな小さな手間を一日中くり返していました。先輩に「その作業、アプリで消せるよ」と言われて入れたのが最初のきっかけです。ここでは、実際に自分の Mac に入れてから手の動きが変わったアプリだけを 10 個紹介します。どれも無料で試せるものばかりなので、気になったものから入れてみてください。

## Raycast でアプリ起動と調べものを 1 か所にまとめられた

以前はアプリを開くのに Dock を探し、計算は Spotlight、クリップボード履歴は別アプリと、頭の切り替えが地味に疲れていました。Raycast はホットキー 1 つで起動、計算、ウィンドウ操作まで完結します。まずは入れて、`⌘ + Space` を Raycast に割り当てるだけです。

```bash
brew install --cask raycast
```

拡張機能を入れれば Jira や GitHub の検索も同じ窓から叩けるので、ブラウザのタブを開く回数が目に見えて減りました。慣れると Spotlight に戻れなくなります。

## Rectangle でウィンドウ配置がキーボードだけで終わる

左右に並べたいだけなのに、毎回ウィンドウの端をドラッグして幅を調整していました。地味ですが 1 日に何十回もやると集中が切れます。Rectangle を入れると、ショートカット一発で半分・最大化・中央寄せが決まります。

```bash
brew install --cask rectangle
```

自分は `⌃ + ⌥ + ←` を左半分、`⌃ + ⌥ + →` を右半分に割り当てています。エディタとブラウザを並べる動作が一瞬になり、マウスに手を伸ばす回数がかなり減りました。

## Homebrew でアプリの導入と管理をコマンドに寄せられた

新しい Mac や検証用の環境を作るたび、公式サイトから dmg を落としてドラッグ&ドロップしていました。入れ忘れも多く、何が入っているかも曖昧でした。Homebrew を使えばインストールも管理もコマンドで揃います。

```bash
brew install --cask google-chrome
brew list --cask
```

さらに `Brewfile` にまとめておけば、新しい端末で `brew bundle` を 1 回叩くだけで同じ構成が戻ります。環境構築のたびに思い出す作業がなくなったのが一番の収穫です。

## iTerm2 でターミナルの履歴と分割が扱いやすくなった

標準のターミナルでログを追いながらコマンドを打つと、画面が流れて直前の出力を見失っていました。iTerm2 は分割表示と検索が強く、過去の出力をさかのぼるのが楽です。シェル統合を入れると、コマンドごとにジャンプできるようになります。

```bash
brew install --cask iterm2
curl -L https://iterm2.com/shell_integration/zsh -o ~/.iterm2_shell_integration.zsh
```

左にログ、右にコマンドの 2 分割で作業するのが定番になり、出力を目で追い直す時間がなくなりました。

## Maccy でコピー履歴から貼り付け直せる

パスワードや URL をコピーしたあと、別のものをコピーして「さっきの文字列どこいった」となるのが毎日の悩みでした。Maccy はコピー履歴を保持し、ホットキーで一覧から選び直せます。

```bash
brew install --cask maccy
```

自分は `⌃ + ⇧ + C` で履歴を開く設定にしています。直前の 1 件だけでなく数件前まで戻れるので、コピーの取り違えによる貼り付けミスがほぼなくなりました。

## AltTab でウィンドウ単位の切り替えができる

同じアプリの複数ウィンドウを切り替えるとき、`⌘ + Tab` ではアプリ単位でしか移動できず、目的のウィンドウにたどり着くまで何度も押していました。AltTab を入れると、Windows のようにウィンドウ単位で一覧が出ます。

```bash
brew install --cask alt-tab
```

プレビュー付きで一覧が出るので、エディタのどのウィンドウに戻るかが一目で分かります。切り替えの迷子がなくなったのは思った以上に大きかったです。

## Karabiner-Elements でキー配置を自分に合わせられた

Caps Lock を押す機会がほぼないのに、左手の小指の大事な位置を占めていて、Ctrl を押すたびに手が伸びていました。Karabiner-Elements でキーを差し替えられます。

```json
{
  "simple_modifications": [
    { "from": { "key_code": "caps_lock" }, "to": [{ "key_code": "left_control" }] }
  ]
}
```

この設定を `~/.config/karabiner/karabiner.json` に書いてから、ショートカットの押し心地が明らかに軽くなりました。指の疲れが減るのは地味に効きます。

## Amphetamine でスリープによる中断を防げた

重いテストやダウンロードを流している間に画面が消え、処理が止まって朝に気づく、という失敗を何度かやりました。Amphetamine はメニューバーからスリープを抑止できます。コマンドで済ませたいときは `caffeinate` も使えます。

```bash
caffeinate -d -t 3600
```

1 時間だけ起動を維持する、といった使い方ができるので、長時間処理を投げて離席するときの不安がなくなりました。

## Stats でメモリと CPU の状況がメニューバーで見える

「ファンがうるさい」「なんか重い」と感じたとき、原因がどのアプリか分からずアクティビティモニタを毎回開いていました。Stats を入れると、CPU・メモリ・ネットワークがメニューバーに常時表示されます。

```bash
brew install --cask stats
```

重いプロセスにすぐ気づけるので、ビルドが遅い原因を探す時間が短くなりました。常に見える安心感があるだけで、作業の引っかかりが減ります。

## AppCleaner で削除後の残骸を残さない

アプリをゴミ箱に入れただけでは設定ファイルが残り、容量をじわじわ圧迫していました。AppCleaner は関連ファイルをまとめて見つけて削除できます。

```bash
brew install --cask appcleaner
```

使わなくなった検証用アプリを消すとき、関連ファイルごと消えるのでディスクの残り容量が把握しやすくなりました。`brew uninstall --zap` と組み合わせるとさらにすっきりします。

## まとめ

10 個並べましたが、共通していたのは「マウスに手を伸ばす回数」と「同じ判断をくり返す回数」を減らすことでした。Raycast や Rectangle のように毎日何十回も使うものは効果が大きく、Karabiner-Elements のような設定系は一度整えるとその後ずっと効きます。全部を一度に入れる必要はないので、まずは 1 つ試してみてほしいです。自分の場合は Raycast から始めて、そこから少しずつ増やしていきました。
