## GitHub Copilot の無料プランで雛形コードを打つ時間が消えた
新しく作る API のバリデーションとテストの雛形を手打ちするのがとにかく面倒でした。拡張を入れて GitHub アカウントでサインインするだけで、無料枠の範囲で補完とチャットが使えます。

```bash
code --install-extension GitHub.copilot
```

型とテスト名の当たりが先に出てくるので、命名や仕様を考える部分だけに集中できるようになりました。合わない提案は Tab で流せるのも気楽です。

## ChatGPT の無料プランはエラーログの壁打ち相手にちょうどいい
原因が分からないエラーを検索窓に貼っても、断片的な記事しか出てこないことが多かった。無料プランでも、ログとコードをセットで投げると候補を絞ってくれます。

```
次のエラーとコードを貼る。原因の候補を確度順に3つ、それぞれの確認方法も。
```

「まずログのここを見る」という順序で返ってくるので、調べる手順が先に決まります。丸投げの答えより、自分で確認する前提の整理として使っています。

## Claude の無料プランで長い仕様書を三分で把握できた
数千行の仕様書や移行手順を読み切る前に、変更点を一覧で欲しかった。無料プランでも長い文章を渡せるので、差分の要約を頼むのに使っています。

```
以下の方針ドキュメントを、実装で守るべき制約と、判断に迷う箇所の2つに分けて要約して。
```

読み始めてから「ここは仕様と矛盾する」と気づく回数が減りました。要約をそのまま信じず、原文の該当箇所を自分で開く癖も同時に付きました。

## Google AI Studio は無料の API キーで長文処理を試せる
個人開発のログ要約をローカルで回すのは重くて無理でした。AI Studio で無料の API キーを発行すれば、スクリプトから直接叩けます。

```python
# pip install google-genai
from google import genai
client = genai.Client(api_key="YOUR_KEY")
res = client.models.generate_content(
    model="gemini-2.5-flash", contents=log_text)
print(res.text)
```

重い前処理なしに検証が回るので、アイデアを試す速度が上がりました。上限に達したら止まるだけなので、課金の心配なく触れます。

## Ollama で社内のコードを外に出さずに相談できた
業務のコードをチャットに貼るのは抵抗がありました。ローカルでモデルを動かせる Ollama なら、その不安がなくなります。

```bash
ollama pull qwen2.5-coder:7b
ollama run qwen2.5-coder:7b
```

ターミナルでそのまま会話でき、関係するファイルも渡せます。最初のモデル取得は待たされますが、以後はオフラインでも動くので出先でも重宝しています。

## Aider は修正とコミットまで CLI でまとめてくれた
「直して」と頼んだあとに、差分を目で追ってコミットする作業が地味に重かった。Aider は CLI で差分を作り、そのままコミットまで走らせられます。

```bash
pip install aider-chat
aider
# /add src/api.py で対象を追加し、指示を打つ
# /diff で確認、/commit でコミット
```

git の履歴に意図が残るので、後から自分の変更を読み返すのが楽になりました。/undo があるので、外し方も気楽です。

## Continue.dev でモデルを用途ごとに差し替えられた
補完は速いモデル、相談は賢いモデル、と使い分けたいのに拡張ごとに画面が違って面倒でした。Continue は設定ファイルでモデルを並べられます。

```yaml
name: my-config
version: 0.0.1
schema: v1
models:
  - name: local
    provider: ollama
    model: qwen2.5-coder:7b
```

用途でモデルを切り替えると、待ち時間と精度のバランスが取れました。設定を共有できるので、チームで同じ環境にそろえるのも簡単です。

## Codeium の無料個人プランは補完の引っかかりが少なかった
補完が重いファイルで固まって、打つ手が止まることがありました。無料の個人プランでも使える Codeium を入れてからは、その引っかかりが気にならなくなりました。

```bash
code --install-extension Codeium.codeium
```

導入は拡張を入れてサインインするだけ。補完を出したくない場面ではすぐ無効化できるので、既存の設定と併用しながら様子を見ています。

## v0 で画面の当たりを数分で作ってから実装に入れた
「まず形を見たい」と言われるたび、HTML と CSS を一から組んで半日使っていました。v0 に画面の要件を投げると、その場で UI のたたきが出てきます。

```
管理画面の一覧ページ。検索欄、ステータスのタブ、行ごとの編集ボタン。Tailwind で。
```

レビューは「この画面で合ってる?」で済むようになり、手戻りが減りました。生成物は叩き台として扱い、細部は自分で直しています。

## Google Colab の無料枠を使い捨ての検証環境にした
検証用のスクリプトを動かすためにローカルの環境を汚すのが嫌でした。Colab の無料枠なら、ブラウザだけで使い捨ての実行環境が手に入ります。

```python
!nvidia-smi
!pip install pandas
```

その場で入れて試し、終わったら閉じるだけ。手元の依存関係が一切荒れないので、ライブラリの比較検証が気軽にできるようになりました。
