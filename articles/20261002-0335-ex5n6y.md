## エディタのフォントサイズを一括調整で作業環境を整える

モニターを複数台使っていると、 1 台目のディスプレイではフォントが小さく見えて目が疲れる。 設定ファイルを開いて個別に変えるのは面倒だった。

```json
{
  "editor.fontSize": 14,
  "terminal.integrated.fontSize": 14,
  "editor.fontFamily": "HackGen, 'Cascadia Code', monospace"
}
```

フォントサイズを統一すると、 エディタとターミナルの視認性が同じになり、 目の疲れが軽減した。 これからは新しい環境に入った瞬間、 この 3 項目を最初に設定する。

## 自動保存でファイルの保存忘れを根絶する

コードを書き終えてブラウザで動作確認しようとするものの、 肩ボキで「保存してなくて動かない」の繰り返し。 自動保存を有効にすると、 ファイルを閉じる前に保存する癨冶がなくなった。

```json
{
  "files.autoSave": "onFocusChange",
  "files.autoSaveWhenHidden": false
}
```

`onFocusChange` に設定すると、 ウィンドウがフォーカスを失うタイミングで自動保存される。 ブラウザに切り替えた瞬間に保存されるので、 未保存によるバグ報告をゼロにできた。

## キーボードでカーソルを複数個操作する

同じ単語を複数箇所で変数名を変更するとき、 1 箇所ずつカーソルを移動するのは時間の無駄。 マルチカーソル機能を使えば、 瞬時に複数箇所を編集できる。

```json
{
  "editor.multiCursorModifier": "altClick"
}
```

`Alt+Click` でカーソルを追加し、 `Ctrl+Shift+L` で選択中の単語と一致する箇所を一括選択できる。 リファクタリング作業の時間が 50% 短縮された。

## Git の競合箇所を視覚的に一目確認する

マージ時に競合箇所をスクロールし続けるのは疲れる。 インライン表示を有効にすると、 どこが競合しているかが一目でわかる。

```json
{
  "git.mergeEditor": true,
  "git.conflictEditor.diffDecorations": "all"
}
```

競合箇所が色分けで表示されるので、 どこを解決すべきか迷わなくなった。 チームでレビューするときも、 競合箇所がすぐに把握できる。

## 括弧の対応関係をハイライトで一瞬確認する

ネストが深い JSON や HTML で、 閉じ括弧がどこに対応するのか考えるのは頭の負担が大きい。 対応する括弧をハイライト表示すると、 コードの構造が視覚的に理解しやすくなる。

```json
{
  "editor.guides.bracketHighlights": true,
  "editor.guides.highlightActiveBracket": true
}
```

対応する括弧が光るので、 どこからどこまでがブロックなのか瞬時にわかる。 特に TypeScript のジェネリクスや複雑な型定義で威力を発握する。

## ファイルツリーを開いているファイルに自動フォーカスする

プロジェクト内で 100 個のファイルを開いていると、 ファイルツリーが見づらくなる。 現在開いているファイルを自動的にハイライトしてくれると、 探す時間がなくなる。

```json
{
  "files.autoReveal": true,
  "search.followSymlinks": false
}
```

`autoReveal` が有効だと、 エディタで開いているファイルがサイドバーで自動的に選択される。 探し回ることなく、 今作業しているファイルの場所がわかる。

## ターミナルをエディタ内で統合してコンテキストスイッチを減らす

コードを書いてすぐにターミナルでテストするために、 VS Code とターミナルを行き来するのは面倒。 統合ターミナルを使えば、 同じウィンドウ内で完結できる。

```json
{
  "terminal.integrated.defaultProfile.linux": "bash",
  "terminal.integrated.defaultProfile.windows": "PowerShell"
}
```

`` Ctrl+` `` でターミナルを開閉できる。 コードとターミナルが同じウィンドウにあるので、 コンテキストスイッチの回数が激減した。

## エラー表示を最小化して集中してコーディングする

コードを書いていると、 赤い波線や警告アイコンが目に付いて集中が途切れる。 必要な情報だけ表示するように設定すれば、 余計な視覚的ノイズが減る。

```json
{
  "editor.minimap.showSlider": "always",
  "editor.hover.enabled": true,
  "editor.hover.delay": 300
}
```

ホバー表示を遅延させることで、 カーソルが止まった瞬間にポップアップが出るのを防げる。 自然にコードを読み進められるようになった。

## 行の折り返しで横スクロールを消す

ログファイルや長い URL を開くと、 横スクロールバーが出てコードが読みづらくなる。 行の折り返しを有効にすると、 縦に読めるので視線の移動が少なくて済む。

```json
{
  "editor.wordWrap": "on",
  "editor.wordWrapColumn": 120,
  "editor.rulers": [80, 120]
}
```

120 文字で折り返しながらルーラー線も表示すると、 コードの長さが視覚的に管理しやすくなる。 特にマークダウンファイルの編集で重宝する。

## ショートカットキーをカスタマイズして手を動かす距離を短くする

マウスでメニューをクリックする回数が多いと、 手の位置がずれて疲れる。 よく使う操作をキーボードショートカットに割り当てれば、 手を動かす距離が短くなる。

```json
[
  {
    "key": "ctrl+shift+d",
    "command": "workbench.action.toggleSidebarVisibility"
  },
  {
    "key": "ctrl+shift+f",
    "command": "workbench.action.toggleSidebarVisibility"
  }
]
```

`keybindings.json` にショートカットを追加すると、 よく使う機能が 1 キーでアクセスできる。 マウス操作を 70% 減らすことができた。
