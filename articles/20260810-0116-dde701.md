## 2. 複数カーソル操作で大量編集（Alt+クリック）
同一修正が必要な複数箇所を同時に編集したい場面は多々あります。Altキーを押しながらクリックすることで、複数カーソルを簡単に設置できます。

```bash
# 実際の使い方
Alt + 左クリック # 複数カーソル設置
Ctrl + Shift + L # すべてのカーソルを選択
```

例えば、変数名を一括変更する際に「名前変更」ダイアログを呼び出すと、すべてのカーソルが同時に名前を変更します。この機能はAPIキーの置き換えやテスト用コードの修正に最適です。

## 3. 行単位のコピー＆ペースト（Ctrl+C / Ctrl+V）
行単位でコードを移動する際、Ctrl+CでコピーしCtrl+Vで貼り付けます。特に関数の引数リストやコメント行を移動する際に有効です。

```bash
# 実際の使い方
Ctrl + C # 1行コピー
Ctrl + V # 1行貼り付け
```

貼り付け時に自動整形が行われるため、インデントの揃えも手間がかかりません。複数行を一度に選択して移動する場合はCtrl+Shift+Vで貼り付け位置を指定できます。

## 4. コードの折りたたみ・展開（Ctrl+Shift+[ / ]）
長い関数やコメントブロックを一時的に隠す際に便利です。Ctrl+Shift+[で折りたたみ、Ctrl+Shift+]で展開します。

```bash
# 実際の使い方
Ctrl + Shift + [ # 折りたたみ
Ctrl + Shift + ] # 展開
```

デバッグ中に関係ない部分を隠して集中したいときに最適。折りたたみレベルを調整することで、必要なコード量を正確に表示できます。

## 5. コードの折り返しを自動化（Alt+Z）
長すぎる行を自動で折り返す設定を有効にします。Alt+Zで行末にカーソルを合わせながら改行します。

```bash
# 実際の使い方
Alt + Z # 自動折り返し
```

特にMarkdownやHTMLの属性リストを書く際に有効です。自動折り返しをオフにしていても、一度設定すると後は自動で適用されます。

## 6. 選択範囲の削除（Delキー）
選択範囲を削除する際、Delキーで一度に削除できます。Ctrl+Shift+Delで行単位での削除も可能です。

```bash
# 実際の使い方
Shift + Del # 1文字削除
Ctrl + Shift + Del # 1行削除
```

不要なコメントやテストコードを一気に削除する際に便利。Ctrl+Shift+Alt+Delで行単位での削除も可能です。

## 7. コメント行の追加（Ctrl+Shift+7）
コメントを追加する際、Ctrl+Shift+7で一括コメントできます。特にテストコードを一時的に無効化する際に最適です。

```bash
# 実際の使い方
Ctrl + Shift + 7 # コメント追加
```

複数行を選択した後に実行すると、すべての行がコメントアウトされます。逆にCtrl+Shift+7をもう一度実行するとコメントを解除できます。

## 8. カーソル位置のジャンプ（Ctrl+G）
特定の行番号に直接ジャンプする際に便利です。Ctrl+Gで行番号を入力し、Enterで移動します。

```bash
# 実際の使い方
Ctrl + G # 行番号入力
```

大規模なファイルを扱う際に特に有効です。行番号を記憶しておけば、特定の関数やコメントに素早くアクセスできます。

## 9. カーソル位置の移動（Alt+クリック）
複数のカーソルを設置する際、Altキーを押しながらクリックすることで、複数の位置を簡単に移動できます。

```bash
# 実際の使い方
Alt + 左クリック # カーソル移動
```

例えば、複数の関数の先頭にカーソルを設置して同時に編集する場合に便利です。Alt+Shift+クリックで複数行を選択することも可能です。

## 10. コードの自動補完（Ctrl+Space）
コードを打ち込む際に、関数名や変数名を自動で補完します。Ctrl+Spaceで補完候補を表示できます。

```bash
# 実際の使い方
Ctrl + Space # 自動補完
```

特に大規模なプロジェクトでは、関数名やクラス名を記憶せずに素早く補完できます。補完候補から適切なものを選ぶことで、タイポミスを防げます。

## まとめ
VS Code のショートカットをマスターすることで、開発効率が劇的に向上します。特に複数カーソル操作や自動補完は、開発プロセスを大幅に短縮します。まずは1つのショートカットから実践してみてください。習慣化することで、自然と生産性が上がります。
