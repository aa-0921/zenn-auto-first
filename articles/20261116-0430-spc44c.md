同じコマンドを毎回手で打ち直していた頃、ログの検索やファイル操作に時間を取られすぎていました。ちょっとした工夫で作業が劇的に速くなることを知り、今では毎日欠かせない10のコマンドを紹介します。

## grep -r で再帰検索が一瞬に
大量のソースツリーから特定の文字列を探すたびに `find . -name "*.js" -exec grep ...` と長いコマンドを組み立てていました。  
```bash
grep -r "TODO" src/
```  
`-r` だけでサブディレクトリごと再帰的に検索できるため、ワンライナーで目的の行に即座にたどり着けるようになりました。

## find + xargs で一括処理がシンプルに
特定の拡張子ファイルをまとめて削除・移動する際、ループを書くのが面倒でした。  
```bash
find . -type f -name "*.log" -print0 | xargs -0 rm -f
```  
`-print0` と `xargs -0` で空白や改行を含むファイル名も安全に扱え、ワンライナーで完結するようになりました。

## jq でJSON整形がコマンドラインで完結
APIレスポンスの確認に毎回エディタを開いて整形していました。  
```bash
curl -s https://api.example.com/users | jq '.[] | {id, name, email}'
```  
`jq` のフィルタで必要なフィールドだけ抽出・整形でき、パイプで次の処理に繋げられるようになりました。

## awk で列指定の集計が一瞬に
CSVの特定列の合計や平均を計算するたびにスクリプトを書いていました。  
```bash
awk -F, '{sum+=$3} END {print sum}' sales.csv
```  
フィールドセパレータ `-F,` と `END` ブロックだけで集計が終わり、ワンライナーで結果が出せるようになりました。

## sed で置換・抽出がファイルを開かずにできる
設定ファイルの一括書き換えに毎回エディタを開いていました。  
```bash
sed -i 's/old_host/new_host/g' config/*.yml
```  
`-i` でインプレース置換ができ、複数ファイルを一発で更新できるようになりました。

## rsync で差分同期が高速に
本番サーバへのデプロイで毎回全ファイルを scp していました。  
```bash
rsync -avz --delete ./dist/ user@host:/var/www/app/
```  
差分だけ転送し、`--delete` で不要ファイルも削除できるため、デプロイ時間が数分から数秒に短縮されました。

## tmux でセッション管理が楽に
長時間実行するビルドやテスト中に接続が切れると最初からやり直しでした。  
```bash
tmux new -s build
# 任意のコマンド実行
# Ctrl-b d でデタッチ
tmux attach -t build
```  
セッションをデタッチ・アタッチできるため、ネットワーク断でも作業を継続できるようになりました。

## fzf で履歴・ファイル検索がインタラクティブに
履歴からコマンドを探すのに `history | grep` を繰り返していました。  
```bash
# .bashrc などに追加
[ -f ~/.fzf.bash ] && source ~/.fzf.bash
# Ctrl-r で履歴検索、Ctrl-t でファイル検索
```  
インクリメンタルサーチで目的のコマンドやファイルに即座に跳べるようになり、タイプ数が激減しました。

## htop でプロセス監視が視覚的に
`top` では並び替えやフィルタが面倒で、CPU/メモリの傾向をつかみにくかったです。  
```bash
htop
# F6 でソート列変更、F4 でフィルタ
```  
カラフルなバー表示とインタラクティブな操作で、ボトルネックを直感的に特定できるようになりました。

## bat でcatの代わりにシンタックスハイライト
プレーンな `cat` ではコードの構造が見えにくく、読み間違いが多かったです。  
```bash
bat --style=plain main.py
```  
行番号とシンタックスハイライトが自動で付くため、ログや設定ファイルを一瞬で把握できるようになりました。
