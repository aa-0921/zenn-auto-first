毎回エクスプローラーをクリックしてファイルを開いたり、メニューからコマンドを探していたのが面倒でした。キーボードだけで作業を完結させたくて、VS Code のショートカットを調べ始めました。

## Ctrl+P でファイルを瞬時に開く
エクスプローラーをマウスで開いてフォルダーをたどる作業に時間がかかっていました。ファイル名の一部を覚えていれば、すぐに開ける方法が欲しかったです。  
```json
// キーバインディングはデフォルトで Ctrl+P
```
Ctrl+P を押すと上部に入力ボックスが出現し、ファイル名を入力すると絞り込まれます。Enter で選択したファイルがすぐに開き、マウスを使わずにファイル間を行き来できるようになりました。これにより、ファイル探索にかかっていた時間が約 70% 削減されました。

## Ctrl+Shift+P でコマンドパレットを呼び出す
メニューを開いて目的のコマンドを探すのが面倒で、毎回同じ場所をクリックしていました。キーボードだけでコマンドを実行したいと思っていました。  
```json
// デフォルト: Ctrl+Shift+P
```
Ctrl+Shift+P を押すと中央にコマンドパレットが表示され、たとえば「git commit」や「format document」などをインクリメンタルサーチで呼び出せます。これでメニューをたどる手間がなくなり、頻繁に使うコマンドへのアクセスが劇的に速くなりました。

## Ctrl+Shift+F でワークスペース内を横断検索
ターミナルで grep を打つか、各ファイルを開いて検索していたのが非効率でした。プロジェクト全体での文字列検索を簡単にしたかったです。  
```json
// デフォルト: Ctrl+Shift+F
```
Ctrl+Shift+F を押すと検索パネルが開き、検索ワードを入力するとファイルごとに結果が一覧表示されます。結果をクリックすると該当箇所にジャンプできるため、ターミナルを立ち上げる手間が省け、デバッグ時の調査が格段に楽になりました。

## Alt+Shift+F でドキュメントをフォーマット
コードを書いた後にインデントが崩れていることに気づき、手動で整形していたのが面倒でした。保存時に自動で整形したいと思っていました。  
```json
// デフォルト: Alt+Shift+F
```
Alt+Shift+F を押すと現在のエディター内のドキュメントが言語に応じたフォーマッタで整形されます。これにより、インデントやスペースの統一が瞬時に行われ、コードレビューでの指摘が減りました。

## Ctrl+K Ctrl+C / Ctrl+K Ctrl+U で行のコメントアウト
デバッグのために複数行をコメントアウトしたいとき、毎行に // を手打ちしていたのが無駄でした。まとめてコメントしたいと思っていました。  
```json
// コメント: Ctrl+K Ctrl+C
// コメント解除: Ctrl+K Ctrl+U
```
選択範囲をした状態で Ctrl+K Ctrl+C を押すと選択行すべてに // が付与され、Ctrl+K Ctrl+U で元に戻せます。これにより、デバッグ時のコードの切り替えが瞬時に行え、ミスが減りました。

## Ctrl+Shift+L で同じ選択範囲をすべて選択
変数名を一括で変更したいとき、毎回ファイルを検索して置換していたのが手間でした。選択した文字列と同じものを全部選びたいと思っていました。  
```json
// デフォルト: Ctrl+Shift+L
```
変更したい変数名を選択した状態で Ctrl+Shift+L を押すと、ワークスペース内の同じ文字列がすべてマルチカーソルで選択されます。その後、新しい名前を入力すれば一括置換が完了し、リファクタリングの時間が大幅に短縮されました。

## Ctrl+D で次の同じ選択範囲を追加選択
変数名を少しずつ変更したいとき、毎回検索して置換していたのが面倒でした。次の一致箇所を順に選んでいきたいと思っていました。  
```json
// デフォルト: Ctrl+D
```
変更したい文字列を選択した状態で Ctrl+D を押すと、次の一致箇所が選択に追加されます。これを繰り返すと、必要な箇所だけをマルチカーソルで編集でき、置換の範囲を細かく調整しやすくなりました。

## Ctrl+` でターミナルを表示・非表示
ターミナルを開くたびにウィンドウの下部をクリックしていたのが面倒で、キーボードだけで切り替えたいと思っていました。  
```json
// デフォルト: Ctrl+`
```
Ctrl+` を押すとパネル内のターミナルが表示され、もう一度押すと非表示になります。これにより、ターミナルへのアクセスが瞬時に行え、ビルドやテストの実行中でもキーボードから手を離さずに作業を続けられます。

## Ctrl+Shift+E でエクスプローラーにフォーカス
エディターからエクスプローラーへ移動するたびにマウスでクリックしていたのが無駄でした。キーボードだけでペインを切り替えたいと思っていました。  
```json
// デフォルト: Ctrl+Shift+E
```
Ctrl+Shift+E を押すとエクスプローラーのペインにフォーカスが移り、矢印キーでフォルダーやファイルを移動できます。これにより、エディターとエクスプローラーを行き来する操作がキーボードだけで完結し、作業の流れが途切れなくなりました。

## Ctrl+Tab で最近使ったファイルを行き来
タブバーをクリックして前後のファイルを切り替えていたのが面倒で、最近使ったファイルを素早く呼び出したいと思っていました。  
```json
// デフォルト: Ctrl+Tab
```
Ctrl+Tab を押すと最近使ったファイルの一覧が中央に表示され、離すと選択したファイルに切り替わります。これにより、タブバーを探す手間がなくなり、関連ファイル間の移動が格段に速くなりました。

## まとめ
これらのショートカットを覚えるだけで、マウスへの依存度が下がり、キーボードだけでコーディングからデバッグまでの流れがスムーズになります。まずは 1 つでも試してみて、自分の作業に合わせてカスタマイズしてみてください。
