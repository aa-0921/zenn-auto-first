本文: 同じ画面のレイアウトを何度も手動で調整していて、時間がかかっていませんか？ Chrome DevTools を使えば、ブラウザ上で直接 DOM を操作し、パフォーマンスを測定できます。しかし、その豊富な機能を使いこなせている人は意外と少ないでしょう。

## 要素のスタイルをリアルタイムで編集できる Elements パネル
ページ読み込み後に DOM 要素を直接操作してしまい、CSS 変更を何度も手動で繰り返すのが面倒でした。DevTools の Elements パネルを開き、要素をクリックするだけで、インプレースで width や color を編集できます。```css .selected { color: #ff6600; }``` 編集が完了したら Enter キーを押すだけで、ページが即座に反映されます。ページを再読み込みする必要はありません。手間いらずのスタイル調整で、デザイナーとのやり取りもスムーズになりました。

## 最終的な計算された CSS 値をワンクリックで確認できる Computed styles
特定の要素の実際のレイアウト値を知るために、スタイルルールを探し回ることがありました。Elements パネルで要素を選択すると、右側に Computed タブが表示され、ボックスモデルやフォントサイズ、余白など、適用されている値を直接確認できます。```js console.log(getComputedStyle(document.querySelector('.target')).marginTop);``` この方法を使えば、CSS カスケードを気にせず、必要な値を即座にコピーしてデバッグに活かせます。

## ネットワーク速度のシミュレーションができる Network パネル
モバイル環境での表示速度を確認したくて、実際のデバイスを何度も切り替える必要がありました。Network パネルで 「No throttling」 をクリックし、「3G」を選択すると、ページ読み込みがシミュレートされます。```bash network.load('https://example.com', { latency: 200, throughput: 500000 });``` レイテンシや帯域幅を調整しながら、キャッシュや圧縮の効果をリアルタイムで確認できます。これで、開発環境だけで快適なユーザー体験を実現できるようになりました。

## JS の実行時間を可視化する Performance パネル
ページが突然重くなる原因を掴めずにいました。Performance パネルでページを記録し、実行時間を分析すると、UI がフリーズする原因が特定の関数の実行にありました。```js function expensiveLoop(){ for(let i=0;i<1e9;i++){} }``` 再生コントロールでフレームをスキップし、ボトルネックを特定できます。このツールで、快適なパフォーマンスの基準を素早く確立できました。

## デバッガーのようなブレークポイントとステップ実行が Sources パネルで可能
JavaScript のバグを特定するのにコンソールログを頼りにすると、コードの実行フローを追うのが大変でした。Sources パネルでファイルを開き、条件付きブレークポイントを設定します。```js break on line 42 if (error) ``` 次に、ステップイン/ステップオーバー/ステップアウトで実行を追い、変数の値を即座に確認できます。このデバッグ機能のおかげで、原因特定にかかる時間が大幅に短縮されました。

## コンソールでワンライナー実行、評価可能なコマンド
繰り返し必要な計算を実行するのに都度スクリプトを書くのが面倒でした。Console パネルで直接 JavaScript を記述し、即座に結果を得られます。```js Array.from({length:10},(_,i)=>i+1).map(x=>x*2);``` 結果を確認したら、コピーして再度実行できます。このインタラクティブな REPL により、小さなユーティリティを素早く作成できるようになりました。

## メモリリークを検出する Memory パネル
長時間ページを表示していると、メモリ消費量が増加し、クラッシュが発生していました。Memory パネルでヒープスナップショットをキャプチャし、Before/After を比較します。```js const snapshot1 = Performance.getMemorySnapshot(); const snapshot2 = Performance.getMemorySnapshot(); const diff = snapshot2.compare(snapshot1);``` メモリ増加の大きいオブジェクトを特定し、適切に解放することで、安定した動作を実現できました。

## ページ品質を自動チェックする Lighthouse 監査
ページの高速化やSEO を意識したいけれど、手動でのチェックは時間がかかりました。Lighthouse タブで Generate report をクリックすると、パフォーマンス、アクセシビリティ、SEO などに関するスコアと具体的な改善策が表示されます。```bash lighthouse https://example.com --output html --output-path report.html``` 得点の低い項目を優先的に修正することで、全体的な品質が向上しました。

## 複数のデバイスレイアウトをプレビューできる Device Mode
レスポンシブデザインの確認に、各デバイスでページをテストするのが大変でした。Device Mode を開き、幅やデバイスを設定し、エミュレートされた画面でページを再描画できます。```css @media (max-width: 480px) { body { font-size: 14px; } }``` 即座にレイアウトの崩れを確認し、CSS を調整できます。この機能で、実際のデバイスなしで多様な画面サイズに対応できるようになりました。

## 再利用可能なコードブロックを保存できる Snippets
同じユーティリティ関数を何度もコンソールに書いていました。Sources > Snippets で新しいスニペットを作成し、名前を付けます。```js // スニペット: formatDate const formatDate = (fmt) => new Date().toLocaleString('ja-JP', { timeZone: 'Asia/Tokyo' });``` スニペットをダブルクリックで即座に実行できます。複数のプロジェクトで再利用でき、作業効率が大幅に向上しました。

## まとめ
DevTools の豊富な機能を紹介しました。Elements パネルでスタイルを直接編集したり、Network パネルで通信状況をシミュレートしたり、Performance パネルでボトルネックを特定したりするなど、それぞれが開発の悩みを解決してくれます。まずは 1 つ試してみてほしい。小さな慣れで日々の作業が格段に楽になります。
