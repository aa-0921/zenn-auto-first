同じコマンドを毎回手で打っていた頃の自分がいる。ターミナルのウィンドウサイズを手動で調整し、メニューバーが溢れ、キーバインドの矛盾にイライラしていた。Macを使うようになって初めて気づいたが、デフォルトの設定では開発の生産性を十分に引き出せない。ウィンドウの配置、キーボードのカスタマイズ、環境構築の標準化。こうした地味な作業こそが、結果的に開発速度を左右する。そこで、私が実際に入れて開発が捗ったと実感したMacアプリを10選で紹介する。

## Rectangleでウィンドウ配置が楽になった
導入前に困っていたのは、ウィンドウを手動でドラッグして半分に分割する作業だった。画面を4分割して並べるときも、マウスでサイズを微調整するのに何度も失敗し、集中が途切れた。Rectangleを使えば、キーボードショートカットでウィンドウを瞬時にスナップできる。``` Rectangle: オプション+コマンド+矢印キーでウィンドウを画面の左右や上下に分割 ``` さらに、画面中央に配置するショートカットも用意されている。設定なしで使えるシンプルな設計で、ウィンドウ操作のストレスが完全に消えた。画面占有率が上がり、同時に開くタブ数が増えて生産性が上がった。

## Karabiner-Elementsでキーバインドの矛盾を解消した
CapsLockをControlに変えたいと思いつつ、他のアプリのショートカットと衝突して悩んでいた。Karabiner-Elementsはキーボードの入力を細かく書き換えることができる。``` json SimpleModificationsでCapsLockをControlに、あるいはEscapeにマッピング ``` 複雑な設定はJSONで記述できるが、SimpleModificationsだけで十分な場合が多い。エスケープキーが親指の届く位置にあり、Vim操作が快適になった。キーバインドの矛盾がなくなり、タイプミスが減った。

## Raycastでアプリ検索とコマンド実行を統合した
Spotlightとアルフレッドを使い分けていたが、起動が重く感じることがあった。Raycastはランチャーとしての機能に加え、コマンド実行やクリップボード履歴も統合できる。``` Cmd+SpaceでRaycastを起動、→でコマンドを実行、Tabでアクションを選択 ``` 拡張機能を入れると、GitHubのIssue管理やTodoリストも呼び出せる。マウスを使わずにキーボードだけで操作が完結し、作業の流れが途切れなくなった。

## Warpでターミナルの現代化を図った
iTerm2の履歴検索が遅く、コマンドの共有が困難だった。Warpは現代的なターミナルエミュレータで、ブロック単位の編集ができる。``` /でブロック入力モードに入り、↑で履歴を補完、Cmd+Enterでブロックを実行 ``` コマンドのブロックを保存してチームと共有できる機能も便利。ビジュアルな差分表示で、以前のコマンドとの違いが一目でわかる。ミスの修正が容易になり、デバッグが高速化した。

## Obsidianで知識をグラフ化した
メモがMarkdownファイルごとに散逸し、過去の調査結果を探すのに時間がかかっていた。ObsidianはローカルのMarkdownファイルをグラフで結びつける。``` [[リンク]]でページを結合し、グラフビューで関連性を可視化 ``` プラグインでダッシュボードやタグ機能を拡張できる。過去のノートを瞬時に呼び出せるようになり、再調査の時間が劇的に減った。知識の蓄積が可视化され、自信を持って開発を進められる。

## Docker Desktopで環境構築を標準化した
「自分のMacでは動く」の言い訳が何度も繰り返され、環境構築に何時間も費やしていた。Docker Desktopを使えば、コンテナ環境を簡単に構築できる。``` docker-compose up -d ``` でローカル環境が立ち上がり、チーム全員が同じコンテナを使える。ポートマッピングやボリュームマウントもGUIで設定可能。環境差異による問題が激減し、新メンバーのオンボーディングも迅速になった。

## TablePlusでデータベースを直感的に操作した
psqlやmysqlコマンドでテーブル構造を確認するのが面倒だった。TablePlusはデータベースをビジュアルで操作できるクライアント。``` 接続設定からホストとポートを入力し、テーブルブラウズでSQLを書かずに操作 ``` データの覧・編集が直感的で、デバッグが高速化した。複数のデータベースに同時に接続でき、クエリの履歴も自動保存される。コマンドを暗記する負担がなくなり、開発に集中できる。

## CleanShot Xでスクリーンショットと録画を統一した
切り取り範囲の調整やGIF録画が手間で、バグ報告が遅れていた。CleanShot Xはスクリーンショットと録画を統合したツール。``` Cmd+Shift+5で起動、スクロールキャプチャやぼかし機能を利用 ``` 画像の編集やアノテーションも内蔵されており、共有用の資料がすぐに作成できる。バグ報告の品質が上がり、開発チームとのコミュニケーションが円滑になった。

## Amphetamineでサスペンドを防いだ
長時間のデプロイやテスト中にMacがスリープして中断された。Amphetamineはサスペンドを防ぐユーティリティ。``` Amphetamineで「常に起動」やチャージ中のみ起動を設定 ``` 特定のアプリが起動している間だけスリープを防ぐことも可能。放置しても止まらないタスクを安心して回せるようになった。デプロイの失敗がなくなり、夜間のバッチ処理も安心して任せられる。

## AppCleanerでアンインストールを完全にした
アプリをゴミ箱に入れても設定ファイルが残り、ディスクが汚れていた。AppCleanerはアンインストール時に関連ファイルも一括削除する。``` AppCleanerにアプリをドロップすると、関連する設定ファイルも一括で削除 ``` 無料版でも十分な機能があり、クリーンな環境を保てるようになった。原因不明の不具合が減り、トラブルシューティングに費やす時間が減った。

## まとめ
まずは1つ試してみてほしい。ウィンドウ管理のRectangleから始めてもいいし、キーボードのKarabiner-Elementsからでもいい。小さな変化が積み重なって、開発のフローがぐっと快適になる。
