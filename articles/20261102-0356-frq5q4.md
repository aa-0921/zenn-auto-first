## Starship プロンプトで視認性と操作性が向上した

**困っていたこと** 従来の PS1 プロンプトは情報量が少なく、Git の状態や実行中のタスクを確認するために別途コマンドを打つ必要がありました。作業の流れが中断されていたのです。

**使い方**
```toml
# ~/.config/starship.toml に追記
[aws]
symbol = "🐉 "

[git_status]
ahead = "⇡${count}"
behind = "⇣${count}"
```
インストール後 `starship init zsh > ~/.zshrc` で反映します。

**変わったこと** プロンプトが一行でリポジトリ名、バージョン管理、仮想環境などを表示するようになり、追加コマンドなしで現在の状況を把握できるようになりました。視覚的なストレスが減り、作業に集中できるようになりました。

## Tmux で快適なターミナルマルチプレインを体験した

**困っていたこと** ターミナルで長時間作業していると、ウィンドウを切り替える手間や、再起動後にセッションを復元する手間が煩わしく感じました。

**使い方**
```sh
# Tmux をインストール
sudo apt-get install tmux
# 開始
tmux new -s myproject
# レイアウトを保存
Ctrl+b : rename-window -t myproject
# セッションを復元
tmux attach -t myproject
```
`Ctrl+b` + `d` でバックグラウンドでセッションを維持できます。

**変わったこと** ターミナル内で複数のペインやウィンドウを分割できるようになり、コマンド実行とログ確認を並行して行えるようになりました。セッションを保存・復元することで、同じ環境を何度も再構築する手間が省けました。

## Fasd でディレクトリ移動が格段に速くなった

**困っていたこと** `cd` で目的のディレクトリにたどり着くまでに、途中のパスを入力したり、履歴をスクロールしたりする手間がかかりました。

**使い方**
```sh
# ~/.zshrc に Fasd を読み込み
source <(fasd --init zsh)
# ディレクトリを検索
cd src
# キーワードで移動
cd rpr   # 「report」ディレクトリにジャンプ
```
`fasd` はよく使うディレクトリを自動的に記憶します。

**変わったこと** 数文字のキーワードでよく使うディレクトリにジャンプできるようになり、`cd` による移動時間が半分以下になりました。過去のプロジェクトへの戻りもスムーズになり、作業の流れが途切れなくなりました。

## Zoxide を使えばディレクトリ検索が格段に楽になった

**困っていたこと** `cd` の履歴が数十件溜まり、目的のフォルダを探すのに時間がかかっていました。

**使い方**
```sh
# インストール
curl -sSfL https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | sh
# ディレクトリを登録
z src
z .config
# 検索して移動
z project
```
`z` コマンドだけで AI 風の候補が表示されます。

**変わったこと** 短くて曖昧なキーワードでも目的のディレクトリを提案してくれるので、迷うことなく移動できます。`cd` の手間がほぼなくなり、`Ctrl+R` で履歴検索する感覚でディレクトリを呼び出せるようになりました。

## Eza で `ls` が快適になった

**困っていたこと** 従来の `ls -l` は見づらく、ソートや色付けも限定的でした。ファイル一覧の確認に時間を取られていました。

**使い方**
```sh
# インストール
sudo apt-get install eza
# 代替コマンドを設定
alias ls='eza --color=auto --group-directories-first'
```
`ls` だけで詳細情報と色付きツリーが表示されます。

**変わったこと** ファイルサイズや権限、一行でのツリー表示が瞬時に得られるようになり、追加オプションを打つ必要がなくなりました。視覚的な情報量が増し、コードリポジトリの確認がぐっと楽になりました。

## Ripgrep で grep が高速になった

**困っていたこと** `grep -r` は検索速度が遅く、大規模なリポジトリでは何分も待たされることがありました。

**使い方**
```sh
# インストール
sudo apt-get install ripgrep
# 使用例
rg -i "TODO" --type py .
```
`rg` は `grep` よりも10倍高速です。

**変わったこと** 数千行のファイルも瞬時に検索できるようになり、エラーメッセージを即座に確認できるようになりました。高速な検索により、コードレビューやバグ追跡の効率が大幅に向上しました。

## Bat でファイル閲覧が快適になった

**困っていたこと** `cat` で表示するとページ移動が不便で、構文ハイライトもありませんでした。コードの確認に手間がかかっていました。

**使い方**
```sh
# インストール
sudo apt-get install bat
# 代替を設定
alias cat='bat --paging=never'
```
`cat file.py` で色付きのソースが表示されます。

**変わったこと** ファイル内をスクロールでき、構文ハイライトも自動適用されるようになりました。ページネーションも設定でき、README やソースコードの確認が格段に楽になりました。

## Fzf でターミナル内ですばやく検索・選択できるようになった

**困っていたこと** 履歴やファイル一覧を `Ctrl+R` で検索しても、選択肢が多すぎて目的のものが見つかりにくかったです。

**使い方**
```sh
# ~/.zshrc に読み込み
source <(fzf --zsh)
# 履歴を検索
fzf --history=:/.zsh_history
# ファイルを選択
fzf --file-widget
```
`Ctrl+T` でファイル選択、`Alt+C` でディレクトリ作成などが可能になります。

**変わったこと** インタラクティブな検索画面で履歴やファイルを選択できるようになり、コマンド入力の手間が省けました。目的のファイルやコマンドを瞬時に呼び出せるようになり、ターミナル操作が快適になりました。

## Thefuck でタイポを自動修正できるようになった

**困っていたこと** タイポによるコマンドミスで、`git comit -a` のように誤った操作を何度も繰り返していました。

**使い方**
```sh
# インストール
sudo apt-get install thefuck
# シェルに読み込み
eval "$(thefuck --alias )"
# 実行
fuck
```
誤ったコマンドを入力すると、修正候補が表示されます。

**変わったこと** 誤入力後の再実行が簡単になり、タイポによる作業中断が減りました。提案されたコマンドを即座に実行できるため、作業の流れが途切れなくなりました。

## まとめ

ターミナル環境を快適にするツールや設定を紹介しました。Zsh + oh-my-zsh で入力補助を強化し、Starship プロンプトで視認性を高め、Tmux でマルチプレイン操作を効率化し、Fasd/Zoxide でディレクトリ移動を迅速化しました。Eza、Ripgrep、Bat、Fzf、Thefuck を使いこなせば、日々のターミナル作業が格段に楽になります。まずは 1 つ試してみてほしいです。
