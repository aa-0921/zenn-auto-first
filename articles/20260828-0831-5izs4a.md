毎回マウスでメニューを探してファイルを開いたり、検索ウィンドウを出すたびに手が止まっていた。キーボードだけでサクサク進められたら、コードを書くリズムが崩れずに済むはずだ。そこで実務で毎日使っているショートカットを 10 個厳選して紹介する。

## Ctrl+P でファイル検索が瞬時に
以前はサイドバーのエクスプローラーをスクロールして目的のファイルを探していた。`Ctrl+P` を押すとクイックオープンが表示され、ファイル名の一部をタイプするだけで候補が絞り込まれる。
```json
{
  "key": "ctrl+p",
  "command": "workbench.action.quickOpen"
}
```
これを覚えてからは、ディレクトリの深さに関わらず 1 秒足らずで目的のファイルにジャンプできるようになった。

## Ctrl+Shift+P でコマンドパレットを即座に開く
設定変更や拡張機能の実行をメニューから探すのが面倒だった。`Ctrl+Shift+P` でコマンドパレットが開き、コマンド名を入力するだけで実行できる。
```json
{
  "key": "ctrl+shift+p",
  "command": "workbench.action.showCommands"
}
```
マウスを使わずに「Format Document」や「Git: Commit」などを即座に呼び出せるため、作業の中断が減った。

## Ctrl+Space でインテリセンスを強制表示
入力中に補完が出ないとき、わざわざ `.` を打ち直していた。`Ctrl+Space` でいつでもサジェストを出せる。
```json
{
  "key": "ctrl+space",
  "command": "editor.action.triggerSuggest"
}
```
タイミングを選ばず補完が出るので、変数名やメソッド名の打ち間違いが激減した。

## Alt+↑ / Alt+↓ で行の移動
コードの並び替えでカット＆ペーストを繰り返していた。`Alt+Up` / `Alt+Down` でカーソル行を上下に移動できる。
```json
{
  "key": "alt+up",
  "command": "editor.action.moveLinesUpAction"
},
{
  "key": "alt+down",
  "command": "editor.action.moveLinesDownAction"
}
```
行単位の並べ替えがキーボードだけで完結し、リファクタリングのスピードが上がった。

## Ctrl+D で次の一致をマルチカーソル選択
同じ変数名を複数箇所修正するとき、検索置換を開くのが大げさだった。`Ctrl+D` を押すたびに次の一致がカーソルに追加される。
```json
{
  "key": "ctrl+d",
  "command": "editor.action.addSelectionToNextFindMatch"
}
```
一括編集が直感的になり、タイポ修正やリネームが数秒で終わるようになった。

## Ctrl+Shift+L で全一致を一括選択
ファイル内のすべての出現箇所を一度に編集したいとき、正規表現置換を書くのが手間だった。`Ctrl+Shift+L` で全一致がマルチカーソルになる。
```json
{
  "key": "ctrl+shift+l",
  "command": "editor.action.selectHighlights"
}
```
一括変更が即座にでき、置換ミスも防げるようになった。

## Ctrl+/ で行コメントのトグル
コメントアウトのために `//` を手打ちしていた。`Ctrl+/` でカーソル行または選択範囲のコメントをオン/オフできる。
```json
{
  "key": "ctrl+/",
  "command": "editor.action.commentLine"
}
```
デバッグ用の一時コメントを素早く切り替えられ、コードの可読性を保ちやすくなった。

## F12 で定義へジャンプ、Alt+F12 でピーク定義
関数の実装を確認するたびにファイルを探していた。`F12` で定義元へ移動、`Alt+F12` でインライン表示が可能。
```json
{
  "key": "f12",
  "command": "editor.action.revealDefinition"
},
{
  "key": "alt+f12",
  "command": "editor.action.peekDefinition"
}
```
コンテキストを失わずに実装を確認できるため、読み解きのストレスが減った。

## Ctrl+Shift+E / Ctrl+Shift+F でエクスプローラー・検索パネルをフォーカス
サイドバーをマウスでクリックする動作が地味にストレスだった。`Ctrl+Shift+E` でファイルツリー、`Ctrl+Shift+F` で全文検索に即座にフォーカスできる。
```json
{
  "key": "ctrl+shift+e",
  "command": "workbench.view.explorer"
},
{
  "key": "ctrl+shift+f",
  "command": "workbench.view.search"
}
```
パネル切り替えがキーボードだけで完結し、思考の流れを切らさずに作業できる。

## Ctrl+K Ctrl+S でキーボードショートカット一覧を開く
自分が設定したキーバインドを忘れたとき、設定ファイルを探すのが面倒だった。`Ctrl+K Ctrl+S` でショートカット一覧が開き、検索・編集が可能。
```json
{
  "key": "ctrl+k ctrl+s",
  "command": "workbench.action.openGlobalKeybindings"
}
```
カスタマイズしたショートカットを即座に確認・修正でき、環境構築の手間が減った。

## まとめ
まずは 1 つ試してみてほしい。キーボードだけで操作が完結すると、コードを書くリズムが途切れず、開発スピードが確実に上がる。
