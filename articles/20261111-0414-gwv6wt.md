同じ操作を毎回マウスでメニューから選んでいたせいで、コードを書く手が止まることが多かった。特にウィンドウの移動、スクリーンショット、クリップボード履歴の呼び出しは、何度も繰り返すたびにストレスが溜まっていた。そこで、標準のショートカットを見直し、足りないものは `defaults` や Karabiner‑Elements で自分好みに割り当てた。以下が実際に導入して効果を感じた 10 個のショートカットだ。

## 1. ⌘+Space で Spotlight 検索が瞬時に
**困っていたこと**  
アプリ起動やファイル検索のたびに Dock や Finder を開いていた。  
**使い方**  
標準で有効だが、インデックス再構築で速度を安定させるコマンドを用意しておくと安心。  
```bash
sudo mdutil -E /
```  
**変化**  
キー一発で目的のアプリやファイルに到達でき、起動までのタイムラグがほぼゼロになった。

## 2. ⌃+↑ で Mission Control を即座に表示
**困っていたこと**  
複数のデスクトップを行き来する際、トラックパッドの 3 本指スワイプが誤動作しやすかった。  
**使い方**  
システム設定 → キーボード → ショートカット → Mission Control で「Mission Control」に `^↑` を割り当て。  
```bash
defaults write com.apple.symbolichotkeys AppleSymbolicHotKeys -dict-add 32 "<dict><key>enabled</key><true/><key>value</key><dict><key>type</key><string>standard</string><key>parameters</key><array><integer>65535</integer><integer>126</integer><integer>262144</integer></array></dict></dict>"
```  
**変化**  
デスクトップ切り替えが指一本で完結し、作業コンテキストの移動がスムーズになった。

## 3. ⌘+Tab → ⌘+Shift+Tab でアプリ切り替えを往復
**困っていたこと**  
頻繁に前のアプリに戻るとき、マウスで Dock をクリックしていた。  
**使い方**  
標準の ⌘+Tab に加え、逆順移動を `⌘+Shift+Tab` で操作。設定不要。  
```bash
# 確認用：現在のキーバインドを表示
defaults read com.apple.symbolichotkeys AppleSymbolicHotKeys | grep -A2 27
```  
**変化**  
前後どちらにも一瞬で移動でき、コンテキストスイッチのストレスが激減した。

## 4. ⌃+⌘+F でウィンドウをフルスクリーン化
**困っていたこと**  
ウィンドウの最大化ボタンを毎回クリックしていた。  
**使い方**  
システム設定 → キーボード → ショートカット → ウィンドウ → 「フルスクリーン」に `^⌘F` を割り当て。  
```bash
defaults write com.apple.symbolichotkeys AppleSymbolicHotKeys -dict-add 33 "<dict><key>enabled</key><true/><key>value</key><dict><key>type</key><string>standard</string><key>parameters</key><array><integer>65535</integer><integer>3</integer><integer>1572864</integer></array></dict></dict>"
```  
**変化**  
コードエディタやブラウザを即座に全画面にでき、集中モードへの切り替えが一瞬で済むようになった。

## 5. ⌘+Shift+4 → Space でウィンドウ単位スクリーンショット
**困っていたこと**  
範囲選択でウィンドウを切り出すたびに微調整が面倒だった。  
**使い方**  
`⌘+Shift+4` 押下後、Space キーでカメラアイコンに切り替え、対象ウィンドウをクリック。  
```bash
# 保存先をクリップボードのみに変更（ファイルを作らない）
defaults write com.apple.screencapture target clipboard
killall SystemUIServer
```  
**変化**  
ウィンドウ単位の撮影がワンキーで完結し、後処理の手間が消えた。

## 6. ⌘+Shift+V でクリップボード履歴を呼び出し（Maccy 連携）
**困っていたこと**  
コピーしたテキストを後から探すたびに履歴アプリを開いていた。  
**使い方**  
Maccy をインストールし、設定で「Show history」に `⌘+Shift+V` を割り当て。  
```json
// Karabiner‑Elements complex_modifications 例
{
  "title": "Maccy history via Cmd+Shift+V",
  "rules": [
    {
      "description": "Open Maccy clipboard history",
      "manipulators": [
        {
          "type": "basic",
          "from": { "key_code": "v", "modifiers": { "mandatory": ["left_command", "left_shift"] } },
          "to": [{ "shell_command": "open -a Maccy" }]
        }
      ]
    }
  ]
}
```  
**変化**  
履歴がポップアップで即座に出るため、過去のコピーを探す時間がほぼゼロになった。

## 7. ⌃+Space で iTerm2 をホットキー起動
**困っていたこと**  
ターミナルを開くたびに Spotlight や Dock を経由していた。  
**使い方**  
iTerm2 → Preferences → Keys → Hotkey → 「Create a Dedicated Hotkey Window」に `^Space` を設定。  
```bash
# 設定確認用（plist から抜粋）
defaults read com.googlecode.iterm2 HotkeyChar -int 32
```  
**変化**  
どこにいても一瞬でターミナルが現れ、コマンド実行までの導線が極めて短くなった。

## 8. Space で Quick Look プレビュー
**困っていたこと**  
ファイルの中身を確認するたびにアプリを開いていた。  
**使い方**  
Finder でファイル選択後、Space キーを押すだけ。設定不要。  
```bash
# Quick Look プラグイン追加例（Markdown 対応）
brew install qlmarkdown
qlmanage -r
```  
**変化**  
画像、PDF、コードなどを即座に確認でき、不要なアプリ起動が激減した。

## 9. ⌃+⌘+D で辞書・翻訳をその場で表示
**困っていたこと**  
英語のドキュメントで単語を調べるたびにブラウザ検索していた。  
**使い方**  
システム設定 → キーボード → ショートカット → サービス → 「辞書で調べる」に `^⌘D` を割り当て。  
```bash
defaults write com.apple.symbolichotkeys AppleSymbolicHotKeys -dict-add 70 "<dict><key>enabled</key><true/><key>value</key><dict><key>type</key><string>standard</string><key>parameters</key><array><integer>65535</integer><integer>2</integer><integer>1572864</integer></array></dict></dict>"
```  
**変化**  
カーソル位置の単語を瞬時に定義・翻訳でき、読解スピードが上がった。

## 10. ⌘+Control+Space で絵文字・記号ピッカーを呼び出し
**困っていたこと**  
コミットメッセージやコメントに絵文字を入れるたびに Web でコピーしていた。  
**使い方**  
標準で `⌘+Control+Space` が割り当て済み。未設定ならシステム設定 → キーボード → 入力ソース → 「絵文字と記号を表示」で確認。  
```bash
# 確認用
defaults read com.apple.symbolichotkeys AppleSymbolicHotKeys | grep -A2 160
```  
**変化**  
インラインで絵文字を挿入できるようになり、コミュニケーションの表現力が手軽に向上した。

## まとめ
ここで紹介した 10 のショートカットは、いずれも「マウスやメニュー操作をキー一発に置き換える」だけで、日々の開発フローが明らかに速くなる。まずは 1 つ試してみてほしい。
