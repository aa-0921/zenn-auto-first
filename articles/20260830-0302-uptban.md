## Inoreader でキーワードアラートを自動化
特定の技術キーワード（例: “Kubernetes”）を含む記事だけを通知したかった。Inoreader の「ルール」機能でキーワードを設定し、Slack に Webhook で飛ばす。
```json
{
  "trigger": "keyword",
  "keyword": "Kubernetes",
  "action": "webhook",
  "url": "https://hooks.slack.com/services/XXXX/YYYY/ZZZZ"
}
```
これにより、関心分野の記事だけがリアルタイムで届くようになった。

読んだ記事を後で振り返るため、テーマごとにまとめたかった。Flipboard の「マガジン作成」で記事をドラッグ＆ドロップし、公開または非公開で保存できる。


## Pocket で後で読むをワンクリックで完結
ブラウザで気になった記事をその場で保存し、後でまとめて読みたかった。Pocket のブラウザ拡張または `pocket-cli` でワンタッチ保存が可能。
```bash
# pocket-cli 例
pocket add "https://example.com/awesome-article" --tags "react,performance"
```
未読リストが溜まらず、週末に一括で消化できるようになった。

## Instapaper でハイライトとメモを残す
記事中の重要箇所を後で検索したかった。Instapaper のハイライト機能でテキストを選択し、メモを付けると自動でエクスポート可能。
```bash
# Instapaper API でハイライト取得例
curl -H "Authorization: Bearer $TOKEN" \
  "https://www.instapaper.com/api/1.1/bookmarks/list?folder=archive&limit=100"
```
後で `grep` するだけで必要な知識が即座に見つかる。

## Raindrop.io でタグベースのナレッジベース化
ブックマークが増えすぎて検索が困難だった。Raindrop.io でコレクションとタグを併用し、CLI から `raindrop-cli` で一括登録・検索ができる。
```bash
# raindrop-cli 例
raindrop add "https://example.com" --tags "go,microservices" --collection "Backend"
```
タグで絞り込めば、目的のリソースが秒で出てくる。

## GitHub Trending を gh コマンドで毎日取得
トレンドリポジトリをブラウザで見るのが面倒だった。GitHub CLI `gh` でトレンド API を叩き、毎日朝に JSON を取得して Slack に投稿する。
```bash
# gh api でトレンド取得（非公式エンドポイント）
gh api /repos/trending --jq '.[] | "\(.author)/\(.name) - \(.description)"' | head -20
```
朝の立会いで「今週の注目 OSS」を即座に共有できるようになった。
